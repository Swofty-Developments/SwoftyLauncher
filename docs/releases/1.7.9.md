# 1.7.9

Swofty Launcher for F1 25 1.7.9 finishes the 1.7.8 start fix.

## Fixes

- A game the launcher builds with another player's row ids gives each of those rows the lent id, even when a record of an addon that is off in that build holds it. 1.7.8 accepted the id and then built the row with another one, so the start was still refused.
