# 1.10.43

Swofty Launcher for F1 25 1.10.43 reports races that get stuck while unloading sooner, on both copies of the game.

## Diagnostics

- When a session gets stuck while unloading, such as the loading screen after a race that never ends, the load-stall report is now written after 60 seconds instead of 3 minutes, so it is there before most players close the game. Loading a session still waits 3 minutes.
- On the EA app copy of F1 25, that report now names the step the game is waiting on, as it already did on the Steam copy.
