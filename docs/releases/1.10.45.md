# 1.10.45

Swofty Launcher for F1 25 1.10.45 makes Send Logs and the crash screen more useful after long sessions, and adds new tools for addon makers.

## Fixes

- **Send Logs** always includes the crash report, and the newest crash dump when it fits. After a long session the other logs could fill the bundle first and leave them out. When a crash file can't be sent, the bundle says why.
- A crash late in a long session is now matched to its known problem. The crash screen read only the start of very long game logs, so it said no known problem matched.
- Playing a saved race in Theatre now counts as a replay, so addons that act during replays do so there too.

## Diagnostics

- When the loading screen after a race never ends, the report now names the track worlds the game is still waiting on and their state, and every race unload logs them. Steam copy only for now.
- `SWOFTY_SPEECH_LOG=all` in the game's environment logs every voice line the game posts, not only the first four. See [Speech](/reference/std/speech).

## Standard library

- **Chart appearance.** Native charts take optional appearance options: text sizes, chart and plot surfaces, borders, grids, rounded blocks, images and line widths. See [Chart options](/reference/addons/launcher-api/chart-options).
- **Videos per box.** `content.package` 1.9 lets a box redirect the game's videos to its own.
- **A box's own track world.** `content.box_assets` 1.2 adds the `world` kind, so a box can carry its own copy of a track's world groups.
- The [Failures, damage and retiring](/std/systems/failures) page describes each wheel corner state, `sessions::disqualify` and reading a car's speed with `live::speed_kmh`.
- The knowledge base has 1,562 new rows for the track, world and weather code, and 1,889 more rows are fully read.
