# 1.9.10

Swofty Launcher for F1 25 1.9.10 fixes Time Trial replays, lets far more season addons run together and gives HUD addons a timing tower.

## Time Trial

- Replays save for every new best again. A restart in the middle of a lap counted the cut-short run as your session best, so no full lap after it saved a replay for the rest of the session. Now only laps the game confirms valid save a replay or count as your best, and a rejected or slower lap no longer replaces your best lap's replay.
- Time Trial no longer stutters while you drive: the launcher read the current track twice a second during a session, which cost up to 0.6 s on some frames. It now reads it once per session.
- A new lap now waits a few seconds for its replay and uploads together with it, so a lap on the boards no longer shows up first without its replay.

## Seasons and addons

- The game no longer crashes at start-up with a Progressive career on alongside Classic Seasons and SWOFTY seasons of the same year. Two cars of one year asked for the same engine sound, so the second car was left out, and Progressive's season lists then pointed at a car the game could not find. That car now keeps its place and shares the other car's engine sound.
- Pressing an era tile no longer crashes the game when a game mode has more than 9 setup modes, as it did with about 15 season addons on.
- Vehicle and team ids now run to 16382, so about 76 season addons fit together instead of about 44.
- Addon creators can mark an entrant list as **virtual** (the `virtual-list` database op, or `"virtual_list": true` on a `content.package` 1.3). A virtual list takes no stat id and no setup mode slot, so a season pack with one list per year is no longer limited to 255 lists or 32 per setup mode.
- When a build runs out of setup mode or season ids (the game stops at 31), the error now says why and how to share a mode instead.
- The tracks table is read by its real row name, so track facts apply when a season box is pressed.

## HUD addons

- `hud.element` 1.1 lets a HUD addon build a full timing tower: rows repeated for each car, stacks and centred groups, the game's own team and series logos, any value the game shows, timed slide and fade motion, and hiding or wrapping stock HUD parts, on the HUD, replay and spectator screens. `templates/hud-tower` is a 30-row starting point.

## Overlay

- The in-game overlay draws on games started through the NVIDIA app's present layer, and with DLSS Frame Generation through Streamline.

## Launcher

- If the game sits on a loading screen for too long, the launcher writes what every game thread is waiting on to the log and to Send Logs, so stuck loads can be fixed.
- The Discord banner at the top of the News page can be dismissed, and it stays dismissed.
