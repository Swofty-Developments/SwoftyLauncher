# 1.10.41

Swofty Launcher for F1 25 1.10.41 brings the game's telemetry feed to the EA app copy.

## Fixes

- On the EA app copy of F1 25, addons that read the game's telemetry feed now get car data. The EA copy is protected and doesn't list its network functions where the launcher looked for them, so the feed stayed empty there. The launcher now finds them in the running game instead. The Steam copy is unchanged.
