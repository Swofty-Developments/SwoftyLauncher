# 1.9.88

Swofty Launcher for F1 25 1.9.88 stops F1 25 crashing on start-up with a track add-on whose nationality the game doesn't know, such as Manhattan Street Circuit.

## Fixes

- F1 25 no longer crashes on start-up, before the menu, with a track add-on whose `nationality` names no `entrants.nationality` row. Manhattan Street Circuit 1.3.9 and 1.3.11 set `united_states`, where the game's row is `usa`, and every Play with it on crashed at `F1_25.exe+0x249beeb` (`+0x249526b` on the EA app). The build sets such a nationality to `default` and warns `nycsgp: nationality united_states is not an entrants.nationality row, default used`. See [The database](/reference/installing-tracks#the-database).
