# 1.9.91

Swofty Launcher for F1 25 1.9.91 makes the Online page load track layout pictures only as their rows come on screen.

## Fixes

- Opening **Online** fetched the layout picture of every custom track at once, more than 500 of them. The server allows 30 layout reads a minute, so it refused most of them, and the refused ones were fetched again on every launch. The page now fetches a track's layout only when its row is on screen, at most 4 at a time and 20 a minute, and sends your Discord sign-in with them. When the server answers that there were too many requests, the page waits as long as the server asks, 60 seconds when it doesn't say, before it fetches another. Fetched layouts stay cached on disk and show without a request on the next launch. Refused ones are not cached and are tried again when their row is next on screen.
