# 1.9.79

Swofty Launcher for F1 25 1.9.79 runs Wheel Dash and other add-ons that use the game's empty menu node on F1 25 1.0.145 in Steam and the EA app, and applies a box's race tyre change rule.

## Add-ons

- Wheel Dash and other add-ons that use the game's empty menu node work on Steam F1 25 1.0.145.2472 and the EA app's 1.0.145.
- `swofty/game.hpp` and `game.rs` have `k_Vm_EmptyNodeHandle`, the game's empty menu node handle, and `Car_Tyre_ChangeToNextCompound`, the tyre change of a pit stop.

## Seasons

- A box with `race_tyre_change: false` keeps each car's compound and wear at race pit stops, and the stop still refuels. Before, the core did not install the rule and race pit stops changed the tyres. `loader.log` says `[pit] race tyre change rule armed` when the rule is on; `SWOFTY_RACE_TYRE_RULE=0` turns it off. See [Fuel rules per box](/std/systems/sessions#fuel-rules-per-box).
