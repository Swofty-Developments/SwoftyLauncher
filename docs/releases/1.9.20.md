# 1.9.20

Swofty Launcher for F1 25 1.9.20 fixes a crash at start-up with a large set of season addons.

## Fixes

- F1 25 no longer crashes at start-up with a large set of season addons on, such as SWOFTY 2015 to 2024 with Progressive Career. The launcher sized the game's database before load without counting the seasons' special liveries, so on some profiles it came out just short of the size where the database grows. The last season's new rows were then turned away after the others were laid out, which left gaps another addon's drivers pointed at. The plan now counts every row the load adds and keeps some room to spare, and an addon that doesn't fit is left out whole before anything is laid out.
- `loader.log`'s room line says how many database keys were planned, how many the load asked for, and whether the database was sized up.
