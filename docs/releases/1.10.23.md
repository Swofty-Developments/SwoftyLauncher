# 1.10.23

Swofty Launcher for F1 25 1.10.23 fixes a crash on startup when more than 32 season lists are installed for Grand Prix boxes.

## Fixes

- Fixed a crash on startup when more than 32 season lists are installed (Grand Prix boxes): the extra seasons are now left out and named in the launcher, instead of the game crashing. Turn some season addons off to get a left-out season back.

## Addon API

- Once an entrant setup mode names 32 lists (31 in `swofty_f1` while a virtual package needs `swofty_virtual_list` there), the core leaves out each further `content.package` that would add one, in load order. Its box stays hidden, and the launcher lists `entrant list <list> left out` under the addon. Lists that database ops add past 32 are cut to the first 32 at boot, and the launcher lists them under the core. See [Virtual lists](/std/content#virtual-lists).
