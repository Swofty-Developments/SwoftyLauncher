# 1.10.42

Swofty Launcher for F1 25 1.10.42 lets several timing tower addons run together and adds detail to career load-loop logs.

## Fixes

- Several timing tower addons on together, such as SWOFTY 2010, SWOFTY 2011 and TV Timing Tower, no longer make the Track Position list too big to start. Each addon's tower now takes only its own space.

## Diagnostics

- When a career keeps loading a race weekend it has already run, the log now records the weekend's progress, its current session and every calendar item running that day, so these loops can be traced to their cause.
