# 1.10.21

Swofty Launcher for F1 25 1.10.21 lets add-ons add their own entry to the game's HUD editor and draw where the player puts it.

## Addon API

- Add-ons can add their own entry to the game's HUD editor with a `hud.slot` record, and draw where the player puts it (`swofty/hud_slot.hpp`). The player moves, resizes and switches the entry off like a stock widget, and the game keeps that placement with its own. See [HUD slots](/reference/std/hud-slots).
- `swofty dev pack` now packs HUD files and the sprites they name.
