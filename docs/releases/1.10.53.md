# 1.10.53

Swofty Launcher for F1 25 1.10.53 fixes a start-up failure left behind by a patched front-end menu file, and adds diagnostics that help pin down crashes with many add-on models and boots that stall on the warning screens.

## Fixes

- Play no longer fails with "migrate_to_f1_world does not enter enter_f1_world_container" when an earlier session left the game's front-end menu file patched.

## Changes

- Send Logs now explains two known F1 25 crashes: running out of room for car model parts on full grids, and a crash as a session ends.
- Logs now show how full the game's model part pool is when a session loads and 5 s after it starts, to help diagnose crashes with many add-on models.
- If the game stays on the warning screens for a minute without reaching the title screen, Send Logs now includes a report of what the game is busy with.
