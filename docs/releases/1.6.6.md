# 1.6.6

Swofty Launcher for F1 25 1.6.6 shows each driver's platform icon where the game hid it and adds 275 experimental game bindings for addons.

## Launcher

- Driver rows (timing tower, driver list, leaderboard and results) show each driver's Steam or EA icon where the game left it out.

## Standard library

- Addon authors: 275 more game functions and fields are available as experimental bindings in `swofty/game`.
