# 1.9.15

Swofty Launcher for F1 25 1.9.15 brings back the frame rate that In-game leaderboards has cost since 1.9.8, adds a Download track button and track authors to Time Trial boards, and fixes a Time Trial crash and a Play bug.

## Performance

- In-game leaderboards no longer lowers the frame rate in careers, Grand Prix and other modes. Since 1.9.8 its Time Trial hooks ran in every mode and checked game memory in a way that is slow on Windows. They now run only in a Time Trial session, and the core's memory checks are cached.
- The career check no longer runs in Time Trial or Grand Prix, where it cost 7 to 11 ms each time.
- The lap recorder no longer asks the game for the track on every tick.
- The player name scan and other background scans run only when something needs them, instead of for the whole session.

## New

- A Time Trial board for a track you don't have shows a **Download track** button when the track is on the Addon Browser.
- Addon tracks show their author on Time Trial boards and in the track lists. Tracks with the same name also show which addon they come from.

## Fixes

- Opening Time Trial no longer crashes the game when the game's GAME log channel is turned on in `SWOFTY_GAME_LOG_CHANNELS`.
- On the EA app copy of the game, Time Trial laps record whether the session was dry or wet. Before, the lap had no weather and the leaderboards turned it down with "the lap has no usable board".
- Play works again for profiles whose names start with a dash. New profile names can't start with one, and when a launch fails the play bar shows why.
- Shader previews no longer flash a console window for each pass.
