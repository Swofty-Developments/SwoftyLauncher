# 1.8.17

Swofty Launcher for F1 25 1.8.17 stops a startup crash caused by careers that need a database addon that's off, fixes a crash in Time Trial on the Supercars box, and unblocks updates for launchers whose data folder sits inside the install folder.

## Careers and saves

- A career made while a database addon was on, such as More Engine Suppliers, needs that addon whenever the game loads the save. The game reads every career in the save when it starts, so with the addon off it crashed at Press to Start, whichever career you picked.
- After each session the launcher now records the database addons that own car, engine, team, driver or head rows for each career saved in that session.
- When one of those addons is off or uninstalled, **Play** asks first and names the addon and the careers. Turn the addon back on, or restore a save from before. **Play anyway** still starts the game.
- Only the careers in the save that profile starts with count: its own launcher save with **Use launcher saves** on, otherwise the Steam save.
- Turning off, removing or uninstalling an addon now warns when a career needs it.

## Time Trial

- Time Trial on the **Supercars** box no longer crashes while the session loads. The first cars on the grid now get their AI racing lines from a car further down when they have none of their own.

## Installing and updating

- A launcher whose data folder is inside its install folder couldn't install updates and stayed on its old version. The update bar now says so and links to [Moving the data folder](/guide/installation#moving-your-addons-and-saves) instead of failing silently.
- The installer no longer accepts a data folder inside the install folder.
