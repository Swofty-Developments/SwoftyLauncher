# 1.7.6

Swofty Launcher for F1 25 1.7.6 fixes the load-order errors Simplified for Swofty 0.13.0 showed, and updates offline play.

## Addons

- Addons in **Built In**, such as Simplified for Swofty, no longer show **Needs X above it** or **Changes rows that X adds**. They can't move, and the build loads them after every addon they require or load after. **Order for me** leaves them in place.

## Offline play 0.3.13

- The game folder's `version.dll` loads into the game before offline play's hook, so mods load on EA app copies the game used to start with Windows' own `version.dll`, such as copies in `D:\Xbox Games`.
- Offline play no longer writes a log line for every process the game opens, which made some boots slow and logs very large.

## EA app

- Race Start runs on the EA app build: the flow reader it needs resolves there.

## Launching

- The launcher can start F1 25 straight into the screen it needs.
