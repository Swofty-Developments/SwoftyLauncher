# 1.9.82

Swofty Launcher for F1 25 1.9.82 shows tables and side-by-side columns in add-on descriptions, version changelogs and news posts.

## Add-ons

- Add-on descriptions, version changelogs and news posts show pipe tables: a header row, an alignment row (`:---` left, `:---:` centred, `---:` right), and bold, italics, inline code and links in cells, with `\|` for a `|` inside a cell. A table wider than the page scrolls sideways. See [Markdown](/reference/addons/publishing#markdown).
- `::: columns`, with a `::: column` for each column, puts blocks side by side. Columns share the width and move onto a new line below 220 pixels each.
- The description preview on publish.f1.swofty.net shows tables and columns as the launcher does.
