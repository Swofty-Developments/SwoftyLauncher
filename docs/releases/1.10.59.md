# 1.10.59

Swofty Launcher for F1 25 1.10.59 stops a stray backup file from blocking Play. Creators can give a track a separate circuit intro for the F1 2026 box and a Time Trial background, and eight more game bindings are now usable.

## Fixes

- Play no longer stops with "UI edit(s) break rules the game's UI loader enforces" when the game folder holds a copy of one of the game's archives, such as `flow_race - Copy.erp` or `bakflow_race.erp`. The launcher now edits only the game's own archives and leaves copies alone.

## For creators

- A track record's `video` can name one circuit intro for every box or one per box (`f1`, `f1_2026`), and the new `time_trial_video` names the background the Time Trial track select plays. See [Circuit intro video](/std/systems/tracks#circuit-intro-video).
- Eight bindings for the power unit panel, the car setup screen and the career hub laptop tab are now exported as `experimental`: `vt_Sess_PuPanel`, `site_Sess_PuPanel_Constructed`, `Sess_PuPanel_Destroy`, `vt_Game_CarSetupVm`, `Game_CarSetupVm_Destroy`, `Game_CarSetupVm_OnDeactivate_Thunk`, `vt_Career_HubLaptopTab` and `site_Vm_SharedTabModelVtable`. See [Bindings](/reference/addons/bindings).
