# 1.6.4

Swofty Launcher for F1 25 1.6.4 lets a box set its own DRS rule, adds registries for R&D trees and the driver market, and starts EA app copies from Play.

## Launcher

- EA app copies: the vanilla profile starts F1 25 as the EA app installed it, and a launcher run as administrator starts the EA app with your own rights. When the EA app takes out the offline play stub, the session says it is repairing, and the repair dialog says to use the vanilla profile if it happens again.
- F1 2012 Season's cars no longer load forever at added tracks such as Istanbul Park. Its track layers point every track at a 2012 world that only stock tracks ship, so the build gives each added track one made from its own world.
- With F1 2012 Season and Classic Seasons on together, Classic Seasons cars no longer load F1 2012 Season's cars and engines. A registry record pinned on a stat id that a database row already holds, a stock row or one an older addon adds, takes the next free id and keeps it while that row is there.
- Box changes (a box's entrant list, DRS rule and Time Trial list) are dropped when the game rebuilds its game modes, and applied again at the next box press, so they never write into modes the game has freed.
- Sessions with many routed files open files faster: the core finds a routed file by its hash instead of checking every route.

## Addon authors

- **DRS per box.** A `rules.drs` record sets the three laps of a DRS group (race start, red flag restart, safety car end), and a box's `content.package` names it in `rules.drs`. A 2010 box can keep DRS shut for the whole race, while every other box keeps its own rule. See [DRS per box](/std/systems/power-units#drs-per-box).
- **R&D trees.** A `career.rnd.tree` record adds or edits nodes in a team's R&D tree, in every upgrades group or in the one it names. A career sees the change at its next load, and saved progress stays on the nodes it still finds by label. See [R&D trees](/std/systems/career#r-d-trees).
- **The driver market.** A `career.market` record sets who retires, who is fired and the driver rating each team asks for. See [The driver market](/std/systems/career#the-driver-market).
- `career.rnd.tree` and `career.market` are experimental (features `registry_career_rnd_tree` and `registry_career_market`): their shape can change before they are stable.
- A record whose `stat_id` a database row holds under another label moves to a free id and logs it once per game start. See [Stat ids](/std/registry#stat-ids).
