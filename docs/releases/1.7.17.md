# 1.7.17

Swofty Launcher for F1 25 1.7.17 repairs imported car packs' texture arrays and fixes a career crash caused by two addons sharing an id.

## Crashes

- Imported car packs that replace whole archives now get the texture array repair that 1.7.15 added for resource-level changes. A team logo array whose view is wider than its image removes the GPU at boot (`DXGI_ERROR_DEVICE_REMOVED`). The build report logs each repair as an `erp:` line.
- An addon that gives its rows fixed `stat_id` values keeps them when an addon earlier in the load order adds rows to the same table. Before, the earlier addon could take one of those ids, so the later addon's career pointed at the wrong row and crashed. With F1 2010 Season and Progressive Career both on, start a new career after updating.

## Build errors

- When an addon adds a resource that the game's own copy of the archive already has, the build error now says the file was probably changed outside the launcher, and to remove hand-installed mods and then Repair the game in the EA app (Steam: Verify integrity of game files).
