# 1.9.48

Swofty Launcher for F1 25 1.9.48 stops a career prompt that named an addon the career doesn't use.

## Warnings

- "Careers that need addons" no longer names an addon you removed when an installed addon now provides the career's team, car or driver. This appeared since 1.9.45, mostly for careers on SWOFTY seasons after a Classic Seasons addon was removed. Careers already marked this way are corrected the next time you press Play.
- When an addon needs several other addons that are off or not installed, the launcher names all of them at once. Before, it named one for each press of Play.
