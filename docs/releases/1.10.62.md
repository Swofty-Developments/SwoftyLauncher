# 1.10.62

Swofty Launcher for F1 25 1.10.62 catches a crash that could strike at the start of a race on some installs.

## Fixes

- The start of a race could crash when the content loaded for a session used ids that one of your saved careers had already reserved for other content: the game then looked up a team record that wasn't there and fell over. The launcher now keeps a session's ids consistent so the record resolves, and it leaves the ids your saved careers hold on disk untouched.
