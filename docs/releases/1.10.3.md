# 1.10.3

Swofty Launcher for F1 25 1.10.3 pins a Back button on add-on pages and stops writing a crash report when F1 25 is closed on purpose.

## Launcher

- Add-on pages have a **Back** button pinned at the top that stays in view while the page scrolls. Escape, Alt+Left and the mouse back button do the same.

## Fixes

- Closing F1 25 from the launcher, with the game window's close button or through the core's settings restart wrote a crash report as if F1 25 had crashed. A close that was asked for now writes none, and `loader.log` says `TerminateProcess(1) ends a close the game was asked for`. A crash just before the close still writes its report.
