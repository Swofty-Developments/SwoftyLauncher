# 1.9.80

Swofty Launcher for F1 25 1.9.80 gives a custom or split-screen session on an add-on box's grid that box's content, carries on without ads when it can't write their folder, and gives a slow add-on helper 60 s to start.

## Seasons

- A session of another game mode that loads an add-on box's grid, such as split screen or a custom session, makes the box's content active as a press of the box does: a season's HUD, its `car.profile` handling and its strings, such as SWOFTY 2011's KERS. Before, the box's content stayed off in those sessions. `loader.log` says `[apply] <mode> session content follows the loaded list: <package>`. See [Track views per box](/std/content#a-track-is-in-every-year).

## Launcher

- When the launcher can't write its ad folder, it no longer stops on a Microsoft Edge "data directory" message; it carries on without ads and offers to restart as administrator.
- After **Stop**, when F1 25 or the EA app still holds some game files, the log names the files that are not back yet instead of saying the game files are rolled back.

## Add-ons

- A slow add-on helper gets 60 s to start before it is marked failed (it used to be 5 s), and `helper.log` records the start time.
- Legacy Career's Pit Wall page no longer fails with `missing field tone`: a text block's tone defaults to neutral.
- `live::tyre_icon_texture(vehicle)` (Live table version 5) returns the fitted visual compound's icon reference for the image service. See [Tyre images](/reference/std/live#tyre-images).
