# 1.9.19

## Changes

- `loader.log` has two more `[perf]` lines every minute. The first lists the `VirtualQuery` calls that swofty code makes, with their time, module and top call sites, and how many pages the core's memory checks looked up. The second has the process's CPU use beside the CPU use of the threads that swofty code started. The busiest probes in the minute line now show calls per second.

## Fixes

- `swofty test session grand_prix` with the F1 2026 box no longer crashes while the session loads. The session now starts under a game setup mode that offers the box's grid, `f1_26` for F1 2026, and `loader.log` names the setup mode it picked.
