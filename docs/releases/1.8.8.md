# 1.8.8

Swofty Launcher for F1 25 1.8.8 lets a shader config switch itself off outside a race, and keeps the Shaders page Preview's play bar and triggers strip on screen in short windows.

## Shaders

- `view.menu` is on in the menus and on loading screens, whenever no session is running, so a config can switch itself off outside a race. See Rules › Only on track:

  ```toml
  [[when]]
  name = "menus"
  on = "view.menu"
  fade_in_ms = 0
  fade_out_ms = 0
  [when.set.rewind_video]
  enabled = false
  ```

- The view's replay, paused, photo, cutscene and spectating flags reach rules on track. `view.camera` isn't read in game yet.
- The Preview's clip shrinks to fit the window, so the play bar and the triggers strip stay on screen in short windows and with Windows scaling.
