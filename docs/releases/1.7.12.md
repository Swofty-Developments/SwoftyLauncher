# 1.7.12

Swofty Launcher for F1 25 1.7.12 brings the new shader system, fixes several crashes and keeps careers on the right tracks.

## Shaders

- Post-processing shaders run once a frame before the HUD, with their own textures and live settings. PolyphoniX Native 0.3.0 needs this version.
- Shader addons pack their `.hlsl` files, textures and `.cube` looks when published.

## Crashes

- The pit crew and garage crew scene guards are on. In 1.7.11 they were built but not switched on. A team's third car no longer crashes a session at load, and an imported track without garage crew scenes no longer crashes the garage.
- A box with more teams than the track has garages no longer crashes the garage slot assignment.
- A track whose AI line has an incomplete set of corners no longer crashes the AI. `[ai] corner start` in `loader.log` names the car once.
- Opening the Time Trial leaderboards no longer crashes when a board's view is missing.
- A showroom or front-end tile whose entrant list an import removed is left empty instead of crashing the game.
- When the game stops itself after detecting a corrupted stack or an invalid call (0xc0000409), it writes a crash report, and the launcher says what happened.

## Careers and tracks

- A track addon keeps its track id when you turn other tracks on or off, so a career's calendar stays on the same circuits. When a career's round uses a track whose addon is now off, the crash notice names the missing track.

## Memory

- The AUDIO_BUNDLE heap is 96 MiB instead of 43 MiB (64 MiB with less than 12 GB of RAM), so careers that load several seasons of car audio don't run out. `SWOFTY_AUDIO_BUNDLE_MB` sets it, and `0` keeps the game's size.
- The save temp heap is 200 MiB instead of 75 MiB, so a large profile no longer aborts while saving. `SWOFTY_SAVE_TEMP_MB` sets it.

## Addons

- An imported mod that spells a car archive's path with different capitals (`F1_2026_vehicle_package`) keeps its file when a track addon is on, and the track's ERS settings go on top of it. Two addons putting the same file are named in the build log.

## Downloads

- A download that slows to a trickle (under 4 KB in 60 s) reconnects and resumes where it stopped, up to five times, and then stops with an error that names the slow server instead of hanging.

## EA app

- When antivirus blocks the EA offline stub (`EAAntiCheat.GameServiceLauncher.exe`), the launcher says so and Send Logs names it, instead of leaving only the EA app's repair prompt.

## Updates

- An update only removes files that an earlier update installed, and it refuses to update a launcher folder that holds your addons, profiles or saves. Before this version, an update removed addons kept inside the launcher's own folder, for example after moving the whole folder to another drive by hand.
- When the data folder you chose under **Keep addons, profiles and backups in** is missing (for example a drive that isn't connected), the launcher and the installer stop with an error naming it instead of starting with an empty data folder.
- The update to 1.7.12 still runs 1.7.11's code. If you moved the launcher's folder by hand and your addons are inside it, copy the `addons` folder somewhere else before you update.

## For addon makers

- `swofty test session grand_prix <box> <track>` and `swofty test session time_trial <box> <track>` start F1 25 straight into a Grand Prix session or a Time Trial garage, with `team=`, `driver=`, `session=` and `laps=`. See [Sessions](/std/testing#sessions).
