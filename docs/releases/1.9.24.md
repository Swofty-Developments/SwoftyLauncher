# 1.9.24

Swofty Launcher for F1 25 1.9.24 fixes a crash when saving careers whose calendar had grown.

## Fixes

- A career no longer crashes the game while it saves because its calendar grew. When a season's calendar repeated a race, the game loaded every stored calendar entry as every event that shares its id, so each load added races and each save stored them, until the save ran out of memory and closed the game. The launcher now loads each stored entry as one event, and a calendar that has already grown is put back to its season's races the next time the career loads. `loader.log` says how many entries a career stored and how many events it loaded.
