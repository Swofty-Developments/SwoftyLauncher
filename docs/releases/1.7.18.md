# 1.7.18

Swofty Launcher for F1 25 1.7.18 fixes replay and flashback crashes on 24-car grids, a shader crash after a resolution change and a save crash with large profiles, makes imported handling edits take effect, and stops the Saves page from freezing the launcher.

## Crashes

- Replays and flashbacks no longer crash on grids of 24 cars, such as My Team or a season with 24 entrants (1.7.16 and 1.7.17). The replay recorder guard from 1.7.16 now steps in only above 24 cars.
- Changing the resolution or display settings in game with a shader pack on no longer crashes the graphics driver. Shader passes now keep the depth buffer they read alive until the GPU is done with it.
- Saving a large profile (many careers and managers) no longer runs out of the game's save memory pool ("SAVE_PROPERTY_BAG_TEMP"). The pool is now 512 MiB on machines with 12 GiB of RAM or more, and 320 MiB below that. `SWOFTY_SAVE_TEMP_MB` still overrides it, up to 1024.
- Continuing a career whose current track isn't in its calendar (for example Miami in a 2016 Progressive Career) no longer crashes while the game reports the career activity. `[career]` in `loader.log` notes it once. Steam only; `SWOFTY_ACTIVITY_RESUME_GUARD=0` turns it off.
- A ready overlay archive whose texture array view disagrees with its image now goes through the build's texture array repair instead of loading as it is. A view wider than its image removes the GPU at boot.

## Addons

- Car handling files (`.vtf`) from imported archives are now built into the game's own archive. Before, an edit that kept the file the same size, such as a mass change made with EGO ERP Archiver, was loaded at run time and had no effect in game.
- When another addon left rows above a table's count, an addon adding rows to that table now adds after them and raises the count, instead of failing the build with "already exists". The build report names the rows.
- "Order for me" only appears for warnings it can fix, and says when nothing needed to move. Stat ids the build renumbers no longer show as a lost change, and the warning names whether the winning addon loads above or below.

## Saves

- The Saves page no longer freezes the launcher. It rebuilds in the background only while it's shown and its save folders change, and keeps each snapshot's details between loads.
