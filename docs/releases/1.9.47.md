# 1.9.47

Swofty Launcher for F1 25 1.9.47 corrects two messages that named the wrong cause.

## Warnings

- The warning that careers "use rows from addons that aren't installed or on" no longer appears for a career on a season addon's team, car or driver while that season is on. If the season is off, the warning names it.
- When no installed addon provides a career's team, car or driver, the warning says so. It no longer says the game can crash at the splash.

## Crashes

- When the game loses the graphics card, the crash window names overlay addons only when the overlay was drawing at that moment. Before, it named them whenever the profile had any, and players turned off addons that had nothing to do with the crash.
