# 1.9.84

Swofty Launcher for F1 25 1.9.84 logs the career's current weekend at Team HQ and a career session that ends right after it starts.

## Logs

- Each time Team HQ opens in a career, `loader.log` lists the current round, whether its weekend is not started, in progress or complete, the current session and how many sessions are complete. A weekend in progress with no session complete is logged as `[career] weekend already started, session never ran`. See [Weekend diagnostics](/reference/std/career#weekend-diagnostics).
- When a career session ends within 2 seconds of its start, `loader.log` says `[career] session ended <N> ms after start`, with the weekend and the calendar items running that day. It replaces `[career] hub left at once`, which also appeared at the start of every career session.
