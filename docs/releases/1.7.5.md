# 1.7.5

Swofty Launcher for F1 25 1.7.5 keeps career addons to their own careers and fixes the crashes players sent in this week.

## Careers and addons

- A career addon only changes its own career mode. Classic Career and Progressive Career can be on in the same profile.
- The **Addons** page warns when an addon's dependency is missing or off, and when the load order puts an addon below one it has to override.
- An addon without a `compat` block installs as an F1 25 addon for any game build and launcher.
- When two addons add the same track, the error names both addons.
- Long pages in **ADDON SETTINGS** scroll: past 18 rows the list follows the highlighted option.
- Team logos from addons are built on top of the launcher's own overlay archives, so logo addons and season addons show together.
- The track guard reads a box's team and car counts even when the box has no setup mode, and assumes the box's grid when it can't read them.

## Crashes fixed

- A crash entering a session when a car's AI asset group was missing, seen with Supercars and community tracks.
- A crash loading a session when a team had more cars than garages, in the pit lane and in the garage crew.
- A crash in the garage setups screen when a setup had no owner.
- A crash in the AI controller when a car's controller set was not readable.
- A crash in the Thrustmaster wheel display when its car had no entrant.
- A slow boot is no longer closed by the game's own hang check while it is still loading.

## EA app

- 29 more game functions resolve on the EA app build, so more addons work there.
- The launcher checks an EA app copy against the EA app's own install record.
- The Steam save import never runs for an EA app copy or while a launch is in progress.

## Telemetry

- Teams that addons add report the 2026 stock team ids in the 2026 UDP format.
