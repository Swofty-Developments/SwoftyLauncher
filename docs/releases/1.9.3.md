# 1.9.3

Swofty Launcher for F1 25 1.9.3 fixes the slowdowns 1.9 brought to the menus and Time Trial, and makes more laps count.

## Fixes

- With **Time Trial boards** on, the game's menus could run at a few frames per second: the launcher asked the game for the current track twice a second in every menu, and each answer took up to half a second. It now does that only during a Time Trial session.
- Time Trial no longer stutters as you cross the line. The lap recorder reads the car 60 times a second instead of every frame, looks up the track and team once per session, and writes the lap file off the game's thread.
- Laps on the game's own tracks and cars now save their replay too, so **Add to game** works for them on the leaderboard.
- A lap recorded right after the car sat still at the line no longer goes back in time at its start, which got genuine laps refused by the leaderboard.
- If the leaderboard server can't be reached as the game starts, the launcher keeps asking in the background, and laps set after it answers count.
- On the **Online** tab, a filter with no laps (for example **No assists**, which nobody has used yet) now keeps the filter bar and shows **Show all laps**, instead of an empty page you couldn't leave.
