# 1.8.9

Swofty Launcher for F1 25 1.8.9 keeps addons loading at the right time when another program opens a window inside the game before the game's own.

## Loader

- A visible window that another program puts inside the game in its first 30 seconds, such as an overlay or tuning tool, is no longer taken for the game's window. Addons that change the game database, such as the season boxes in Grand Prix and Time Trial, load in time again. The log names the window and the program it belongs to.
