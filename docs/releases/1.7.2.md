# 1.7.2

Swofty Launcher for F1 25 1.7.2 fixes launcher saves for Windows user folders with letters outside English.

## Game fixes in the core

- Launcher saves start when the save folder's path has letters outside English, such as `C:\Users\Hüseyin\…`. Before, the core refused the folder, F1 25 closed before the title screen (exit code 93), and only **Play once with your Steam saves** worked.
