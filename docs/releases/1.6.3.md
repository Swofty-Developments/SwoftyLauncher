# 1.6.3

Swofty Launcher for F1 25 1.6.3 keeps the ids addons give new rows within what the game reads, and stops a practice crash at imported tracks.

## Launcher

- New vehicle packages, drivers, engines and scenarios that addons add get ids the game can store. The game keeps those ids in one byte, so an id past 254 pointed at the wrong row or none: with F1 2012 Season 1.1.1 and Classic Seasons on together, Classic Seasons cars crashed at session load. When the next id would pass the limit, the build takes the lowest free id instead and keeps ids that other addons set. Ids that already fit don't change.
- Two addons that give a scenario the same `statId` no longer clash: the second one gets a free id, and the build warns with both addons.
- Practice at an imported track (Hockenheim, Sochi, Delhi and others) no longer crashes when a track limits warning or penalty comes in. The track acclimatisation programme has no targets at imported tracks, and the game read the first one regardless.

## Addon authors

- Leave `stat_id` and `statId` out of `add-row`; the build gives each new row an id the game can read. See [Stat ids](/reference/ops/database#stat-ids).
