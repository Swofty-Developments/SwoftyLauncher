# 1.9.17

Swofty Launcher for F1 25 1.9.17 fixes the crashes that 1.9.16 brought when entering Time Trial, opening a career or loading a race, and makes addon panels and shaders work with the game's frame generation.

## Fixes

- The game no longer crashes when entering Time Trial, opening a career or loading a race on Windows. 1.9.16 read game memory under an exception guard that Windows couldn't unwind through, and the game closed with a bad stack and no crash report. Memory reads go back to the 1.9.15 way. In Time Trial with In-game leaderboards on, the frame rate is back to where it was in 1.9.15 until the next update brings the faster reads back safely.
- Addon panels in the game, such as Silly Season's, draw with DLSS Frame Generation on when the game presents through a swapchain the core didn't see being made.
- Shaders, their toggle key and live changes work again with the game's XeSS frame generation, which Intel Arc cards use and which the game also sets up with Frame Generation off. The core missed every frame the game presented through it, so shaders ran for a moment and then stopped.
- On the EA app copy of the game, every profile plays on the game's one save. Play's career check and the Saves page now look at that save, so Play warns before a profile starts careers that need addons it has turned off. **Copy careers** is off there, since every profile already shares the save.
