# 1.9.17

## Changes

- `loader.log` has two more `[perf]` lines every minute: the `VirtualQuery` calls swofty code makes, with their time, module and top call sites and the bad pointers the core's guarded reads caught, and the process's CPU use beside the CPU use of the threads swofty code started. The busiest probes in the minute line now show calls per second.
