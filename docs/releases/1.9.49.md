# 1.9.49

Swofty Launcher for F1 25 1.9.49 makes two crash reports more accurate.

## Crash reports

- The crash report says the game stopped while closing only when the whole game was shutting down. Before, a crash while leaving a session or a menu could get that verdict.
- Send Logs records how large each addon HUD screen is against the game's interface limits. A HUD addon that is too large for the game can now be named.
