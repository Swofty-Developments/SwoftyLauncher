# 1.10.58

Swofty Launcher for F1 25 1.10.58 makes one Play error point at the right file. Creators can give a track its own circuit intro video, and three HUD parts now also cover the spectator screen.

## Fixes

- When a file the launcher built for an add-on disappears before it reaches the game folder, often because an antivirus removed it, Play now names that file and says what to do. Before, the message said a stock game file such as `pitstop_24.erp` was missing and asked you to verify the game files, which never helped.

## For creators

- A track record's `video` names the track's own circuit intro, a Bink 2 `.bk2` in the add-on. The launcher places it with the track's other files, in the F1 2026 box's set too, and points the track's intro at it instead of the base track's map. See [Circuit intro video](/std/systems/tracks#circuit-intro-video).
- The `flag_box`, `notifications` and `minimap` HUD parts now also hide the spectator screen's flag, race control banner, minimap and full track map. See [HUD](/reference/ops/hud).
