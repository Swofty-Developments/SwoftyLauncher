# 1.9.14

Swofty Launcher for F1 25 1.9.14 fixes the Time Trial garage freezes and takes more work off the game's threads in Time Trial and races.

## Fixes

- Opening the leaderboard in the Time Trial garage no longer freezes the game. The core walked every board in the game's list on each lookup, which held the game for 10 to 65 seconds on some PCs and could get the game closed by its own watchdog.

## Performance

- The check of the game's ghost download in Time Trial now runs on its own thread, so it no longer costs the game anything per frame. On some PCs it took 5 to 10 ms each time.
- In races, the core no longer reads every car's engine on each physics step unless an addon changes engine power. That was 25 to 28 ms every second.
