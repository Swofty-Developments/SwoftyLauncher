# 1.9.2

Swofty Launcher for F1 25 1.9.2 fixes two crashes.

## Fixes

- On the EA app copy of F1 25, pressing **Back** on the Grand Prix or Time Trial picker crashed the game (1.9.0 and 1.9.1). The core now finds the game's main menu entry point for the copy it is running on, and leaves it alone when it can't.
- With RivaTuner Statistics Server (or MSI Afterburner's on-screen display) running, Frame Generation on and an addon that draws on the in-game overlay, such as Silly Season, the game could crash a few seconds after starting. The overlay now notices RivaTuner and draws the way it did before 1.8.38. The overlay's own hooks also switch on only once they are fully set up.
