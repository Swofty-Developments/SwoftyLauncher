# 1.10.18

Swofty Launcher for F1 25 1.10.18 guards more of F1 25's own animation code, where the game could crash right after Terminal Damage tore a wheel off.

## Fixes

- F1 25 could still crash in its own animation code when an animation was sampled at a time that is not a number outside the places the 1.10.13 guard covers, such as the game's UI animations. Both reports so far came shortly after Terminal Damage's experimental suspension damage tore a wheel off. The launcher now gives such an animation its first frame there as well, instead of letting the game fault. `SWOFTY_ANIM_PACKET_TIME_GUARD=0` turns this off.
- The crash screen now names this crash. When it comes within 10 seconds of Terminal Damage tearing a wheel off, it says the fault is in the game's code and asks you to press Send Logs. If it happens again, it says to turn off Terminal Damage's **Suspension damage from hits (experimental)** and **Suspension damage for AI cars (experimental)** options on the Addons page.
