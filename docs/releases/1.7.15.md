# 1.7.15

Swofty Launcher for F1 25 1.7.15 fixes crashes at boot with Team & Driver Editor and Classic Seasons on together.

## Crashes

- A texture array's view always follows its image. When one addon replaced a team logo array's image and another its view, the game got a view wider than the texture and the graphics device stopped at boot. This happened with Team & Driver Editor and Classic Seasons on together. The build log names each array it fixes (`erp: texture array ...: view said X slices, image has Y; fixed`).
- Rows that addons other than the core add to the game's database go into the game's database file instead of being inserted after it loads, which crashed the front end in some profiles with Career Length and few other addons.
