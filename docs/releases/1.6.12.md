# 1.6.12

Swofty Launcher for F1 25 1.6.12 puts back the stat ids 1.6.10 and 1.6.11 moved, so Grand Prix and career saves from before 1.6.10 load again, and fixes a set of crashes and build stops.

## Launcher

- Grand Prix and career saves from before 1.6.10 load again. 1.6.10 and 1.6.11 gave the rows addons add new stat ids, so a save from earlier couldn't find its teams and cars, and Continue crashed while it loaded. New rows get their ids in load order again, as before 1.6.10. On its first start the launcher reads your earlier game logs and gives each row back the id it had then.
- A Grid Editor edit of a grid another addon adds, such as a Classic Seasons grid, applies once that addon has added the grid. Before, Play stopped with "no row matches" whenever the Grid Editor loaded first.
- An edit whose selector matches several rows takes the first one and the build warns, instead of stopping. More Driver Models can leave two rows for the same driver, which stopped Classic Seasons builds.
- Addons can add drivers past stat id 254, up to 16382. Builds with many driver addons stopped with "no free stat_id up to 254".
- ADDON SETTINGS splits its tiles into pages of 24, with NEXT PAGE and PREVIOUS PAGE. With about 60 or more addons, mods and tracks on, the screen froze when a tile was pressed.
- Team logos are rebuilt only when an archive they're built from changes.
- The launcher finds the signed-in Steam account when Steam leaves `activeuser` at 0.
- A build stops with a clear message, and the setup wizard opens, when a backed-up original game file is missing.
- A broken addon download resumes where it stopped, and a TLS error says what to check.
- A failed addon update leaves the installed version whole.
- The Addons page lists the changes of addons whose op files use templates.

## Game fixes in the core

- Grand Prix Continue loads the entrant list that holds the saved teams when the game leaves the box's list empty. When the saved weekend's track isn't in the build, because the addon that adds it is off, F1 25 closes at the load and the launcher says which track, instead of crashing.
- A Time Trial with Supercars on no longer crashes as the session starts. A car whose tyre class has no slot for the fitted set gets one from its own class.
- A team with three cars in one garage no longer crashes the session load. The third car races without a garage crew.
- The Grand Prix track select refuses a track the box can't run, with a popup that says why, for boxes an addon adds through database edits, such as F1 2012 Season. That box's 12 teams need the garage world it ships, which Mugello doesn't have.
- Team HQ > Standings no longer crashes when a round's track addon is turned off.
- A race weekend whose track addon is off runs on its stock track.
- The game log no longer crashes the game when a message's arguments don't match its text, as when opening a replay.
- UDP telemetry reports a team an addon adds under the stock team it's based on, and an added driver under the stock driver it is, or 255, so overlays such as SimHub show team names and driver names in season addons. `SWOFTY_UDP_STOCK_IDS=0` turns this off. See [UDP telemetry ids](/reference/std/telemetry#udp-telemetry-ids).

## Addon authors

- `cars::live` drives cars from the core through `SwoftyCoreCarOps`: steering lock, clutch, differential, turbo boost, fuel mass, wing and suspension damage, the engine limiter, the final drive and gear ratios, and the `car.built` and `car.reset` events. It's experimental. See [Car physics](/std/systems/car-physics).
- New bindings: pit lane status, tyre refit, the audio queue, and the `session.lap` event.
- Every team row in the built database is a `team.identity` record, `game/<row label>`, on every profile, including the rows season addons add. A read-only addon can map team ids with the registry's `stat_id`.
- A database op whose selector matches no row waits for a later addon to add it, and fails the build only when no addon does. See [Applying changes](/reference/ops/database#applying-changes).
- The bindings document exports 2,116 bindings, up from 802, from vogtmarcel's mapping and verification work.
