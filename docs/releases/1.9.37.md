# 1.9.37

Swofty Launcher for F1 25 1.9.37 writes the composed HUD everywhere the game reads it.

## HUD

- The HUD the launcher composes from addons' HUD elements now goes into every game archive that carries the screens it changes. Until now the in-race HUD archives (`hud`, `hud_player_1`, `hud_player_2`) kept the game's own copies of the bottom cap, the standings table and the Race Control banners beside the composed ones, and with a big element such as TV Timing Tower 0.8.0 that mix could crash the session as the HUD loaded.
- `swofty hud check` lists the archives that carry each screen the composer writes and checks they all agree. A build stops with a message naming the addon if its composed HUD would still leave one of the game's own copies beside it.
