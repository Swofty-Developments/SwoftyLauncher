# 1.10.16

Swofty Launcher for F1 25 1.10.16 guards a crash as a session starts on a track whose marshal lights are outside every marshal light zone, names that crash on the crash screen, and moves career restores still waiting across the 1.10.15 update to the EA app copy.

## Fixes

- F1 25 could crash as a session started on a track that has marshal lights outside every marshal light zone, such as Laguna Seca Grand Prix 3.7.0 by Ashton: as the second session on the track started, or at a session restart. The game drops each such light from its list of marshal lights, and when it drops the first one it then reads before the list. The launcher now ends that step at the start of the list instead of letting the game fault. `SWOFTY_MARSHAL_LIGHTS_GUARD=0` turns this off.
- The crash screen now names this crash. It names the track, says to turn it off, and asks the track's author to add a marshal light zone over every part of the lap that has marshal lights.
- With **Use launcher saves** on, a career restore chosen on the Career Saves page before the 1.10.15 update, of a version the EA app copy saved, stayed with the Steam copy's plain copies when 1.10.15 split them. Such a restore now moves to the EA app copy's plain copies, and the next EA app session applies it. When the EA app copy's plain copies have no copy of that version, the restore is answered as not applied, with where the version is kept. Profiles 1.10.15 already split get this at the next launcher start or **Play** with F1 25 closed. This only affects a restore still waiting for **Play** across the 1.10.15 update. See [Splitting a shared store](/reference/saves#splitting-a-shared-store).
