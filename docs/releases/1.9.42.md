# 1.9.42

Swofty Launcher for F1 25 1.9.42 stops a crash when Theatre opens, and makes load hangs easier to diagnose.

## Theatre

- Opening Theatre no longer crashes the game when a saved highlight belongs to an owner that isn't in the current list. Since 1.9.5 the launcher skipped that highlight's save slot, but the next highlight then read its row from past the end of the list. The rows now stay in order.
- The saved highlights list gets the same guard as the recent highlights list.

## Load hangs

- When the game hangs while a session loads, its report lists the threads that aren't waiting first, with their registers and the game function each one is in.
- While a session loads, the launcher logs the sizes of the per-wheel tyre effect lists, the loop the game was stuck in in four reports. It warns if a list's size is out of range.
