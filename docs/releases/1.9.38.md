# 1.9.38

Swofty Launcher for F1 25 1.9.38 stops texture array merges from dropping other addons' slices.

## Addons

- An `erp.merge-slices` op merges its slices over the array as the addons before it left it, at any slice count, as long as the format and slice size match. Until now it merged over the game's own array whenever an earlier addon had changed the slice count, so every slice that addon added was dropped while the array's view kept the larger count.
- A merge into an array of another format or slice size is refused with a warning naming the addon that left it, and the array stays as it is. An addon's whole-resource put over an array another addon grew is refused the same way. See [Texture arrays](/reference/ops/erp).
