# 1.9.29

Swofty Launcher for F1 25 1.9.29 lets addons back up the save the game actually uses.

## Addons

- Addon helpers have a `save_dir` host call that returns the folder the game reads the active profile's saves from: the EA app copy's save folder, the launcher's own save store when launcher saves are on, or Steam's save folder otherwise. Until now addons only had `steam_save_dir`, which found nothing on the EA copy and, with launcher saves on, pointed at a Steam folder the game wasn't reading. The Career Mode Editor uses it for its save backups and restores from its next version.
