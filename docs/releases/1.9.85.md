# 1.9.85

Swofty Launcher for F1 25 1.9.85 shows your addons' team logos on an EA app copy of F1 25 under Program Files.

## Fixes

- In a game folder under Program Files, such as `C:\Program Files\EA Games\F1 25`, the team logos and badges that SWOFTY seasons, ByDaniX 2010, Classic Seasons, Progressive Career and other addons add show in game. Before a modded session, Swofty Launcher run as administrator makes `swofty/addons/swofty.logos/` and `swofty/addons/swofty.garage/` in the game folder and gives the Users group Modify on them, and F1 25 started by the EA app without administrator rights builds its team logo archives there. Until now those sessions logged `0 slice(s) built into 0 archive(s)` and showed the stock logos. See [A game folder only administrators can change](/using/game-copies#a-game-folder-only-administrators-can-change).
- When F1 25 still can't create files in `swofty/addons/swofty.logos/`, the mod loader skips the logo build and logs `team.logo: the game can't create files in swofty/addons/swofty.logos/ (error N)`. Once the game closes, the launcher shows **Your addons' team logos were not built** with the folder and the Windows error. See [Send Logs](/using/send-logs).
- A team logo archive that fails to write names the Windows error and the path on its `could not be rewritten` line.
