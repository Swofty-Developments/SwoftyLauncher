# 1.10.66

Swofty Launcher for F1 25 1.10.66 fixes F1 25 showing "Game launch error 0x00000004" on every launch after a launcher update.

## Fixes

- Some players saw "Game launch error. Error code: 0x00000004" on every launch after updating the launcher, even with every add-on off. The previous version's offline play had left a file in the F1 25 folder, `swofty\offline\state`, that stopped the new version from setting up. The launcher now removes that file when it belongs to an offline play version that is no longer installed, so the game starts normally again with no manual steps.
- The launcher's logs no longer say offline play was set up for a session when it wasn't.
