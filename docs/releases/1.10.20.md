# 1.10.20

Swofty Launcher for F1 25 1.10.20 lets add-ons read the game's text in its current language, follow every voice line, including the race engineer and driver radio, and read the game's own resources, textures and UI images.

## Addon API

- Add-ons can read any `lng_*` text in the game's current language with `swofty::lang::text`, a voice line's subtitle with `swofty::lang::subtitle` and the language code with `swofty::lang::language`. See [Strings](/reference/std/strings#text-and-language).
- Add-ons can follow every voice line, including the race engineer and driver radio, through the `speech.line`, `speech.line.timed` and `speech.line.end` events from `swofty/systems/speech.hpp`. Each line carries its speaker, category, subtitle key and id, `speech.line.timed` adds its length and `speech.line.end` how long it played. The events fire on the Steam copy of F1 25. See [Voice lines](/reference/std/speech).
- Add-ons can read the game's own resources by `eaid://` URI, decode game textures to RGBA8 and find the texture of a UI image catalogue entry with `swofty/game_assets.hpp`. They read from the player's own game folder. See [Game assets](/reference/std/game-assets).
- Overlays can load an image from memory with `swofty::overlay::load_image_rgba` and draw it like an image loaded from a file. See [Overlay](/reference/std/overlay#images-from-memory-v4).
