# 1.7.4

Swofty Launcher for F1 25 1.7.4 lets addons add to the game's logo and tile arrays instead of copying them.

## Addons

- The new `append-slices` erp operation adds an addon's own slices after the slices already in a texture array, such as the team logos, and sets the array's slice count. Two addons that each append their logos both show, without a conflict. See [Texture arrays](/reference/ops/erp#texture-arrays).
- An addon that uses `append-slices` sets `compat.launcher` to `>=1.7.4`; older launchers reject the operation.
