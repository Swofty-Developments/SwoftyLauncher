# 1.10.8

Swofty Launcher for F1 25 1.10.8 lets add-ons read each car's tyre wear, tyre age, lap and sector times and starting grid position from the live state.

## Addon API

- `live::car_detail(vehicle)` (Live table version 6) returns more of a car's state from the same snapshot as `live::car`: its starting grid position, the wear of each tyre in percent, the laps on the fitted tyre set and in the current stint, the laps completed, the time and sectors of the lap in progress and of the last lap, and the best valid lap with its lap number and sectors. `live::grid_position`, `live::last_lap_ms` and `live::best_lap_ms` return each as a `std::optional`. See [car_detail](/reference/std/live#car-detail).
- These values read on the Steam copy of F1 25, 1.0.145 included. They stay off on the EA app copy, and `loader.log` has an `off on the EA build` line for each of them.
- `SwoftyLiveSession` declares `time_left_s` and `total_laps` with the `SWOFTY_LIVE_SHAVE_TIME_LEFT` and `SWOFTY_LIVE_SHAVE_TOTAL_LAPS` bits. They are not read yet and stay 0, and the struct keeps its size.
- The host test fake sets a car's detail with `fake.detail(vehicle)`.
