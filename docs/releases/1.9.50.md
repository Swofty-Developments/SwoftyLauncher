# 1.9.50

Swofty Launcher for F1 25 1.9.50 fixes the Watch button on the main menu video card.

## Main menu

- Watch opens the video in your browser. On Windows it could open the Documents folder instead, once for every press.
- Pressing Watch several times in a row opens the video once.

## Builds

- A problem while measuring an addon HUD for the logs no longer stops Play.
