# 1.9.32

Swofty Launcher for F1 25 1.9.32 stops a career crash at the start of a session.

## Careers

- A career whose save names a team mate or player driver that F1 25 can't find loads into its sessions again instead of crashing as the session starts (in Game_CareerEventResourceManager_AddDriverMorphData). That driver's morph data is left out, and the loader log names the driver once, so a later report can tell which one it was.
- If that crash still happens, the crash report says your career has a driver F1 25 can't find and what to try.
