# 1.6.11

Swofty Launcher for F1 25 1.6.11 lets Play start when a VR tool has replaced `openvr_api.dll`.

## Launcher

- A game folder whose `openvr_api.dll` was replaced by a VR tool, such as OpenComposite, no longer stops Play with "Your game files have been edited". The launcher logs the changed file and carries on, as it does for the EA AntiCheat files.
