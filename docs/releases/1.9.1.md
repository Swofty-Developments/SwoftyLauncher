# 1.9.1

Swofty Launcher for F1 25 1.9.1 fixes two 1.9.0 problems and adds Spanish.

## Fixes

- If F1 25 had moved to another folder, for example after a fresh Steam install or a library move, Play could refuse with "an earlier session's undo record is for F1 25 in ..., which is gone". The launcher now undoes only the files it can prove it wrote in the current folder, leaves everything else as it is with a note, and starts the game.
- On the **Online** tab, going **Back** after **Refresh** or **Try again** could leave a season or driver page on its loading placeholder. Back now loads the page again.

## Languages

- The launcher is now available in **Español**. Pick it under Settings > Language.
