# 1.7.10

Swofty Launcher for F1 25 1.7.10 makes a direct start clearer and adds graphics crash diagnostics.

## Launching

- When the launcher starts F1 25 straight into the screen it needs, it shows each step with a progress bar from the moment you start until the game is there, and tells you in one sentence what went wrong if it doesn't get there.
- A direct start waits for the game to be ready before it goes on, instead of giving up when the game is still loading.
- While a build runs, the **Building** button cancels it.

## Crashes

- After a crash where the graphics device stopped responding, the next session turns on D3D12 device-removed diagnostics, and a repeat crash's report names the GPU work that didn't finish and any page fault. `SWOFTY_DRED=1` turns it on for every session, `SWOFTY_DRED=0` turns it off.
- A crash in the post-processing hook after its set-up failed is fixed.
