# 1.10.57

Swofty Launcher for F1 25 1.10.57 fixes the launcher closing on its own shortly after Play, a career crash at the first Team HQ exit, and two wrong warnings in the logs. Creators get UI registries, D3D12 command-list observation and new game bindings.

## Fixes

- The launcher no longer closes on its own a minute or two after you press Play. When it restarted, it lost track of the running game and showed Play again while F1 25 was still open.
- A new career that moves more than 40 drivers at once, such as some Progressive Career 2010 starts, no longer crashes the game when you leave Team HQ for the first time. The game's driver-moves message holds 40 changes, so the launcher now sends the rest in more messages.
- When memory runs out while the game saves, the launcher's save capture and its game hooks now stop and log it instead of taking the game down with them.
- On EA app copies installed under Program Files, the session log no longer says "the loader never attached" when it did. The launcher now reads the loader's own log from the launcher's data folder when the game folder refuses it.
- The "Mods did not load" warning and the Send Logs summary no longer report a missed load when the loader ran but the game's own log lines overwrote its first line.

## For creators

- The standard library's UI system adds texture slices, home and F1 World tiles, screens, routes, options and HUD widgets. See [UI](/std/systems/ui).
- Native plugins can observe D3D12 command lists and record scoped compute work. See [Native plugins](/reference/addons/native-plugins).
- New game bindings for the garage setup and vehicles.
