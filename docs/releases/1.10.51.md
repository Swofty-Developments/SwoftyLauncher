# 1.10.51

Swofty Launcher for F1 25 1.10.51 adds a native selection dialog add-ons can open from a button, fixes a career that kept re-running a race it had finished, and updates the bundled offline play component.

## Add-ons

- Add-ons can open a native selection dialog from a button, to pick drivers, recordings or export options. For add-on creators, see Launcher API > Views.

## Fixes

- Fixed an F2 Revamp career that kept loading the round 2 race again after it finished, when its calendar starts the next race weekend inside the last one.

## Changes

- Updated the bundled offline play component to 0.4.1.
