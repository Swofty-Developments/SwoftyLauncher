# 1.9.39

Swofty Launcher for F1 25 1.9.39 changes how the composed HUD animates, to stop a crash as a session loads.

## HUD

- The slide and bar-fill animations the launcher composes for addons' HUD elements carry only their position. Until now each also carried a one-key rotation and scale that did nothing. Depending on where the game placed the clip in memory, reading that rotation could crash the session as the HUD loaded. That was the crash with TV Timing Tower 0.8.0.
- A build stops with a message naming the addon if a composed HUD clip would still carry a one-key rotation.
