# 1.10.54

Swofty Launcher for F1 25 1.10.54 keeps add-on HUD editor rows and add-on track flags that were being dropped, guards against a loading hang caused by a damaged archive, and fixes where team 13 pits in a 26-car race.

## Fixes

- Add-on rows in the game's HUD editor (from add-ons such as PULSE and Driver Momentum) no longer disappear when another add-on, such as 2026 Race Starts, replaces the HUD layout file. The launcher now merges the file instead.
- An add-on track's flag is no longer left out when its flag image is stored a little differently from the game's own flags (for example Autopolis).
- Play now checks every compressed part of an archive it writes, and every archive it copies into the game folder, and redoes any that don't come out right. A bad part used to send the game into a loading hang it never left.
- In a 26-car race with a 13th pit box (the F1 1990 world), team 13's cars now stop at their own box instead of the safety car's spot.

## Changes

- Send Logs now explains invisible tyres after loading a mid-session save: those cars are not damaged and drive normally.
- Send Logs now recognises the crash as a session ends on the EA app copy of the game too.
