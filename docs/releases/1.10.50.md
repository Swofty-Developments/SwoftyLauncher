# 1.10.50

Swofty Launcher for F1 25 1.10.50 fixes Accept on the first-run setup and lets the DB Editor clear fields that mean something when empty.

## Fixes

- When the first-run setup can't save a step, such as Accept on the terms page, it now shows the error on screen. Before, Accept did nothing and the page showed no message.
- Accept on the terms page no longer fails when a temporary file from an earlier try was left behind in the data folder.
- The DB Editor offers **None** for an entrant's Team and Car, a line-up's Driver override and the equal-performance car. These fields mean something when empty (for example, an entrant with no team takes the team from its line-up seat), and before, a value could not be cleared once it was set.
