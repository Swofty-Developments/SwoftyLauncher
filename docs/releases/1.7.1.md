# 1.7.1

Swofty Launcher for F1 25 1.7.1 keeps Play working when an addon's launcher range ends before this launcher.

## Launcher

- An addon whose `compat.launcher` range ends below the running launcher, such as `>=1.6.11, <1.6.13` on 1.7.1, is left out of the build with a warning instead of stopping Play, and so is every addon that needs it. Its author needs to publish an update. An addon that needs a newer launcher still stops Play with the message to update the launcher.
