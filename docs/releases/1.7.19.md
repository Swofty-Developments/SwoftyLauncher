# 1.7.19

Swofty Launcher for F1 25 1.7.19 stops shader packs such as PolyphoniX Native from flickering while you drive, runs them once a frame in menus and loading screens, cuts their CPU time, and adds a Donate to Developers button.

## Shaders

- Shader packs such as [PolyphoniX Native](/using/swofty-addons#polyphonix-native) no longer flicker while you drive. When the game drew the end of its picture in a second command list, the passes ran before it and the frame showed without them, in one or two frames out of a hundred on track. The passes now run in that list, once the picture is whole.
- In menus and loading screens the passes no longer run twice on a frame that two of the game's lists read, which made the glare jump brighter for that frame.
- Shader packs take about 15% less CPU time on the game's threads: each frame writes only the shader views that changed, and most of the game's barriers are noted without a lock. Frame rate on track is unchanged.
- The `swofty/postfx.burst` reader now reads back every presented frame, and `SWOFTY_POSTFX_BURST_DUMP` writes them to a folder ([post-process passes](/reference/addons/postfx#in-game)).

## Launcher

- A Donate to Developers button sits above Send Logs and opens [donate.swofty.net](https://donate.swofty.net/).

## Addons

- Supercars no longer shows an amber clash with every track addon.
