# 1.9.8

Swofty Launcher for F1 25 1.9.8 makes Time Trial lap replays work for everyone and turns the in-game leaderboards on.

## Fixes

- A new Time Trial personal best saves the game's replay and uploads it with the lap, so **Add to game** on the leaderboard puts it in your Theatre. Until now the replay was only saved with **In-game leaderboards** on, which was off by default, so almost no lap had one. Laps already on the boards stay without a replay; your next personal best has one.

## Changes

- **In-game leaderboards** is on by default: the Time Trial leaderboard inside the game shows the Swofty boards, rival ghosts and replays. If you turned it off it stays off; turn it on in **Settings**.
