# 1.10.55

Swofty Launcher for F1 25 1.10.55 makes the offline play download survive a connection that keeps cutting it off, and teaches Send Logs one more crash.

## Fixes

- Play no longer fails after several minutes when the offline play files keep getting cut off while downloading. The launcher now carries on from where the download stopped, gives up on a dead connection in about 30 seconds instead of 6 minutes, and still checks every file before using it. If the download still can't finish, the message says the connection keeps cutting it off and suggests checking a VPN, proxy, antivirus web filtering or DNS.

## Changes

- Send Logs now recognises a crash as a session ends that is mostly seen on PCs short of memory, says how full the PC's memory was, and lists the steps that help.
