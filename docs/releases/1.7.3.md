# 1.7.3

Swofty Launcher for F1 25 1.7.3 brings your careers into launcher saves when Steam lives on another drive or folder.

## Launcher

- The first start after updating finds your Steam save from F1 25's own Steam library, so a Steam install outside `C:\Program Files (x86)\Steam`, such as on `D:`, is imported too. Before, those profiles started with empty launcher saves and your careers only showed when playing from Steam.
- When no Steam save is found, the import is tried again at the next start and once Steam reports who is signed in, instead of being marked done.
- A profile whose launcher save is empty says so on **Profiles > Saves**, with **Import from Steam**, and under Play.
- If you already played on an empty launcher save, **Profiles > Saves > Import from Steam** brings your careers back; the version you replace stays in the career vault.
