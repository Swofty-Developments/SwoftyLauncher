# 1.9.28

Swofty Launcher for F1 25 1.9.28 gets Time Trial laps onto the leaderboards again.

## Fixes

- Time Trial laps are accepted by the leaderboards again. 1.9.26 and 1.9.27 wrote laps to the launcher's data folder first, and the lap's integrity seal looks for the session next to the lap, so laps were sealed without their session and the boards refused them ("another session's nonce"). Laps go to the game folder first again, as they did up to 1.9.25; an EA app copy under Program Files still falls back to the data folder for the file. Laps set on 1.9.26 or 1.9.27 that were refused can't be added afterwards; set them again on 1.9.28.
- Addon season boxes stay in the Time Trial and Grand Prix pickers after a Time Trial on another box. Ending some Time Trials undid the steps that keep the boxes in the wrong order, so boxes such as F1 2012 or Supercars were left out until the game was restarted.
