# 1.7.16

Swofty Launcher for F1 25 1.7.16 fixes two session crashes and explains more startup failures.

## Crashes

- A session with more cars than the replay recorder holds (22), as in some career addons' seasons, no longer crashes. The extra entries aren't recorded, so a flashback may not restore their state. `[replay]` in `loader.log` names the car count once.
- The car setup screen no longer crashes when it opens before the player's car exists.

## Crash notices

- When the game loads the loader but it never reports, the notice names what can stop it: an `Image File Execution Options` value such as `MaxLoaderThreads` on `F1_25.exe`, compatibility flags on `F1_25.exe`, or a security product's module inside the game, with the steps to remove them.
- When a game heap can't get more memory (Ne heap error 0x58), the crash report names the heap and how much memory Windows had left to give, which usually means a page file that's too small.
