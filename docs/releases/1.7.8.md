# 1.7.8

Swofty Launcher for F1 25 1.7.8 fixes a start failure and adds a loading screen with progress.

## Fixes

- A game the launcher builds with another player's row ids no longer refuses to start when one of those ids is held by a record of an addon that is off in that build. Records of addons outside the build don't register that session.

## Launching

- When the launcher starts F1 25 straight into the screen it needs, a loading screen covers the game's own screens from the first frame and shows the current step and a progress bar.
