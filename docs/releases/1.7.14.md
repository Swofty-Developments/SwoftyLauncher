# 1.7.14

Swofty Launcher for F1 25 1.7.14 gives the game more room for large careers and fixes a Team HQ crash and a Saves restore bug.

## Memory

- The game's main heap (GAME_DEFAULT) is 1 GiB instead of 390 MiB (640 MiB with less than 12 GB of RAM), so a career with Progressive and every Classic Seasons year no longer runs out of it at tracks like Sepang. `SWOFTY_GAME_HEAP_MB` sets it. The heap reserves address space and uses memory only as the game fills it.

## Crashes

- Entering Team HQ no longer crashes when an event's track has no track data for the career's season. The event shows no track. `[career] teamhq` in `loader.log` names the track once.

## Saves

- The **Saves** page lists only versions it can restore, and **Restore** finds every version it lists, also after a profile's saves were copied from another profile.

## For addon makers

- A postfx pass that returns NaN or infinity for a pixel leaves that pixel as it was instead of writing it.
