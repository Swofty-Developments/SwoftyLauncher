# 1.10.19

Swofty Launcher for F1 25 1.10.19 fixes profile saves failing with **Corrupted save, data overwrite** after a race highlights save.

## Fixes

- Saving no longer fails with **Corrupted save, data overwrite** after a race highlights save. If your saves already fail, they work again from the first launch with this version. Your save file was never changed: it holds your careers as of the last save that worked.
- On that prompt, **Continue Without Saving** and **Cancel** both leave your save file as it is. Only the progress since the last save that worked is not kept.
- Careers are put back only from the plain copies taken at a profile save. A plain copy taken at the race highlights save is passed over, and only game modes' save containers and the launcher's own are put back.
- The crash screen now names a session in which F1 25 could not save your profile. It says your save file was not changed and asks you to press Send Logs. When the race highlights had gone into the profile save, it says to update Swofty Launcher. See [Send Logs](/using/send-logs).

## Addon API

- `career.saving` and `career.saved` fire only for the profile save. The race highlights save (`savegame@highlights000`) and the game's other saves fire neither. See [career events](/std/systems/career).
