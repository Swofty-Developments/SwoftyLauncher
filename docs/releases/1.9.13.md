# 1.9.13

Swofty Launcher for F1 25 1.9.13 puts Time Trial replays on the leaderboard, tidies the Runs tab filters and fixes a false failure in Restore game folder.

## Fixes

- On the Time Trial Runs tab, seasons and tracks are picked from a Season and a Track dropdown, sorted by name, instead of a button for every season and track that pushed the run list off the screen. Two tracks with the same name show their code after it.
- A lap with a game replay now shows Add to game on its row of the Time Trial leaderboard. Before, the button only showed for runs under review, so no replay could be reached from the board. Rows without a replay no longer show a greyed-out button.
- Restore game folder no longer reports "swofty is not part of the game" because of the launcher's own empty swofty folder. A file left in that folder is now named by its path.
