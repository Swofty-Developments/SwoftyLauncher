# 1.9.13

Swofty Launcher for F1 25 1.9.13 tidies the season and track filters on the Time Trial Runs tab.

- On the Time Trial Runs tab, seasons and tracks are picked from a Season and a Track dropdown, sorted by name, instead of a button for every season and track that pushed the run list off the screen. Two tracks with the same name show their code after it.
