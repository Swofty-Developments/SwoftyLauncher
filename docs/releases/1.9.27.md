# 1.9.27

Swofty Launcher for F1 25 1.9.27 fixes Time Trial replay uploads that got stuck.

## Fixes

- A Time Trial lap's game replay that the leaderboards don't keep, such as one for a lap slower than your best on that board, no longer retries for hours. The server turns those down before it reads the upload, and the connection was cut while the launcher was still sending, so the launcher saw a network error, kept retrying, used up the upload limit and held back your other replays. The launcher now asks for the server's answer when an upload is cut off, drops the replay the server doesn't keep, and waits when it's asked to.
