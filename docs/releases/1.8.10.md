# 1.8.10

Swofty Launcher for F1 25 1.8.10 lets shader rules react to rain, starts the game when an imported track's menu image is broken, and explains what to do when another program holds a game file.

## Shaders

- Shader rules can react to rain: `session.wetness` is how wet the track is and `car.wetness` the water under the car's wheels (the wettest of the four), both 0 to 1, on the Steam copy of F1 25.

  ```toml
  [[when]]
  name = "spray"
  on = "car.wetness"
  from = 0.2
  to = 0.8
  [when.set.rewind_video]
  smear = 0.4
  ```

## Tracks

- An imported track whose menu image can't be read is left out of the menu art instead of stopping **Play** with "surface header is too short". The build notes name the track and the image.

## Launching

- When another program has a file in the game folder open, such as an F1 25 that didn't fully close, a Steam update or file check, or an antivirus scan, the error says so and lists what to close, instead of asking you to run the launcher as administrator.
