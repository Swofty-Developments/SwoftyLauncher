# 1.9.16

Swofty Launcher for F1 25 1.9.16 makes the core's game memory reads far cheaper on Windows, which raises the frame rate with In-game leaderboards on, in Time Trial as well as in other modes.

## Performance

- The core no longer asks Windows about an address each time it reads game memory. On Windows that check took kernel time on every frame, and most of all in a Time Trial session with In-game leaderboards on, where the frame rate could drop to a few frames a second in the garage. Reads now go straight to memory and recover safely from an address that isn't there.
