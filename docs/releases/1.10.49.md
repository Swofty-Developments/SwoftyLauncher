# 1.10.49

Swofty Launcher for F1 25 1.10.49 gives PCs with under 12 GB of RAM more game memory and makes two crash diagnoses more accurate.

## Fixes

- On a PC with under 12 GB of RAM, F1 25's memory for game data is now 1 GB, the same as on other PCs, instead of 640 MB. Profiles with many imported tracks and season packs filled the smaller size while a track loaded, and the game closed. The game uses this memory only as it fills it.

## Diagnostics

- When F1 25's game memory fills up while Progressive Career is on, the crash notice says to keep the SWOFTY season packs on: Progressive Career needs them for the next seasons. Before, it said to play with fewer season add-ons.
- The same notice no longer tells a career player to turn off a track their calendar races at. It says to turn that track off for Grand Prix and Time Trial and keep it on for the career.
- For a crash from an earlier launcher on a PC with under 12 GB of RAM, the notice says the game had less of this memory then, and how to raise it: `"SWOFTY_GAME_HEAP_MB"` under `"env"` in `"launch"` in `config.json` in the data folder (`%LOCALAPPDATA%\Swofty` on Windows).
- Send Logs shortens a very long log to fit and now keeps the lines from the left-out part that identify known problems, so the crash notice still finds them.
