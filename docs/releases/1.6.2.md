# 1.6.2

Swofty Launcher for F1 25 1.6.2 makes registry records load whichever way the game database is built, adds the fields a career with entirely new teams needs, and keeps Time Trial within the 26 vehicles the game supports.

## Standard library

- The core loads at the early stage whenever an enabled addon has registry records, in data files or registered from its DLL. Before, with the database built into the game file (for example with Classic Seasons 2016–2024 on), the early stage stayed off and every boot record was refused. The build log names the addons: "registry: the core loads at the early stage for the registry records of …".
- `team.identity` 1.1 adds `team_boss`, the team principal (a `entrants.characters` row), and `team_base` (a lang key or a literal). New team rows take both, and a field left out keeps the donor team's value. Cores before 1.6.2 ignore the fields.
- `career::apply_teams` dresses all 12 career slots with addon team records, including principal and base, and only touches the season's own data group. Every dress comes off when the career unloads.
- A `career.content` record in a data file makes a career tile with no DLL, the same as `career::content::add`.
- A `content.package` with 12 teams and 24 cars needs no `database` block: the core adds the 12th team to the copied standings row and the extra entrants to the copied entrant list.
- Progressive Career gives a twelfth team a place in the season's standings when a record puts one in slot 12.
- `era.box` 1.1 adds `time_trial.entrant_list`, a box's own Time Trial list. A box whose Time Trial list holds more than 23 cars stays off the Time Trial picker, with a log line.
- A Time Trial session never takes more than 23 cars of one list, on any box including the stock F1 2025 one. The game adds 3 vehicles of its own to a 26-slot table, and a 24-car list crashed the session. Each Time Trial load logs the list and setup mode the game picked.
- Vehicle package and scenario stat ids the core gives out stop at 254, the largest value the game keeps.

## Developer tools

- `swofty test` passes the title screen and the startup notices by itself, reaches the home screen and routes to screens by tile (`home`, `tile <id>`, `wait screen=<name>`). `career load newest` loads a career from a fixture in the save sandbox to Team HQ, and `save now` saves it.
- The compatibility gate prints a note when a `swofty` binary was built without the launcher next to it, since that build orders JSON keys differently.
