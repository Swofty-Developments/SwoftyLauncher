# 1.10.47

Swofty Launcher for F1 25 1.10.47 opens sooner after moving the data folder and records how the Move finished.

## Fixes

- After Settings > Move… copies the data folder to another drive and restarts, the launcher opens its window without waiting for the old copy to be deleted. The old folder is deleted in the background once the window is up. If the launcher closes first, the next start finishes it.

## Diagnostics

- Finishing a Move is logged step by step with how long each step took, both in the launcher's log and in `swofty-data-move.log` next to the data folder.
- Send Logs, including `swofty.exe logs send`, adds the Move's log and records in a `data-move` folder, and its summary says whether a Move or a delete of the old folder is still waiting.
