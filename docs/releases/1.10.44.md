# 1.10.44

Swofty Launcher for F1 25 1.10.44 keeps large add-on downloads from starting over.

## Fixes

- A launcher update no longer restarts the launcher while add-ons are downloading or queued to update. It waits until the add-on updates finish and then installs.
- An add-on download that is cut off, by a restart or a dropped connection, now carries on from where it stopped instead of downloading the whole file again. The finished file is still checked in full before it is installed.

## Diagnostics

- When an add-on download stalls or retries, the log now says so, with the server, how much had arrived and the speed, so Send Logs shows it.
