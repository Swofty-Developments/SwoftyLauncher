# 1.6.10

Swofty Launcher for F1 25 1.6.10 fixes a Time Trial crash, keeps the ids of addon cars stable from one build to the next and writes archives the game can load with less memory.

## Launcher

- A Time Trial on the stock F1 2025 box with F1 2012 Season on no longer crashes as the session starts. A Time Trial takes the cars of every entrant list on its leaderboard, and F1 2012 Season's lists share F1 2025's leaderboard, so the session held 27 vehicles and the game read past its 26-slot vehicle table. Each Time Trial load now counts those cars and leaves whole lists out, addon lists first and never the selected one, until they fit, and puts them back when the session unloads.
- Careers keep their cars when addons change. The rows an addon adds with `add-row` keep their stat ids from one build to the next, in `registry/row-ids.json`, so reordering, updating or adding addons no longer moves the cars a saved career points at. A new row gets an id worked out from its addon, table and label, so the same addons give the same ids on every PC. Game modes, setup modes and seasons stay at 31 or below.
- Archives the launcher and the core write now record each block's size and use a 1 MiB compression window, as the game's own archives do. The game sets aside far less of its fixed archive memory to load them; archives with 8 MiB windows could run that memory out with several season addons on.
- The Addon Browser scrolls smoothly with many addons listed, and the launcher's cards fit narrower windows.
- The launcher's usage pings say whether the game copy is the Steam or the EA one, so the public stats page can show how many players use each.

## Addon authors

- `swofty registry row-ids <addon>` shows each of an addon's added rows with its stat id and where it came from (kept, seeded or worked out).
- A Time Trial takes every entrant list on the selected list's leaderboard. A list copied from `f1_2025` keeps its leaderboard (`f1`) and joins every stock F1 2025 Time Trial; give a season box's lists their own `leaderboard`, as Classic Seasons does with `classic`.
- `tools/erpw.py` writes frames with their content size and a 1 MiB window, and `erpw.py reframe <dir>` rewrites an addon's existing archives that way without changing their contents.
