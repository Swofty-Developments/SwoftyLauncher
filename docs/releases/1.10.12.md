# 1.10.12

Swofty Launcher for F1 25 1.10.12 guards a crash in F1 25's tyre wear estimate and fixes moving the data folder when it is the game's install root.

## Fixes

- F1 25 could crash in its own tyre wear estimate, often right after Terminal Damage's experimental suspension damage tore a wheel off. The launcher now gives that lookup the curve's first point instead of letting it fault. `SWOFTY_TYRE_CURVE_GUARD=0` turns this off.
- The crash screen now explains a crash in F1 25's own tyre wear estimate. When it comes right after Terminal Damage's experimental suspension damage tears a wheel off, it names the two options to turn off. Otherwise it says this is a game fault and asks you to press Send Logs.
- Moving the data folder no longer fails or loses files when the data folder is the game's install root.
- On EA copies, a garage cutscene for a team with no team record, such as a 1990 team, is guarded the way it already is on Steam copies.
- Fixed a misleading career wizard log line.
