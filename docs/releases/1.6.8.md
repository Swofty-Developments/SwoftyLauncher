# 1.6.8

Swofty Launcher for F1 25 1.6.8 fixes a crash at race start and keeps the Addon Browser working when one addon in the registry can't be read.

## Launcher

- F1 2012 Season's HRT and Marussia cars no longer crash a Grand Prix as the session starts. A car whose handling file has no ERS section started with a random ERS mode; the core now resets that car to Medium and logs it. F1 2012 Season 1.1.2 also carries the missing sections.
- The Addon Browser no longer goes blank when one addon in the registry can't be read; that addon is left out instead.
