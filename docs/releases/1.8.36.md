# 1.8.36

Swofty Launcher for F1 25 1.8.36 tags addons with the game copies they were tested on, guards one race crash when a car retires, and fixes new row ids that Check conflicts could lose.

## Addon Browser

- Each addon shows a **Steam** and/or **EA** tag for the game copies its author tested it on, or **Not tested** when the author hasn't said. The detail page shows the same tags.
- A **Platform** filter in the sidebar shows All (the default), Steam, EA or Not tested ([Addon Browser](/using/addon-browser)).

## Launcher

- The two install cards on the Addons page can be closed, and stay closed.
- Mouse-wheel scrolling is smoother in every scrolling list.
- On a window less than 760 pixels tall, the DB Editor folds its page notes behind **About this page**, so the table keeps room for its rows.

## Fixes

- The game could crash at the end of a race or when a car retired, in its lap-time estimate for a car that had just retired. The core now skips that estimate for such a car. Another crash at the same moment, in the red-flag simulation, is not covered yet.
- Pressing **Check conflicts** and then **Play** could lose the ids the check gave to new rows, so a later build could give a career's rows other ids. Play now saves them.

## For addon authors

- `compat.platforms` lists the game copies an addon was tested on, `"steam"` and/or `"ea"`. Set `"compat": { "launcher": ">=1.8.36" }` with it, as earlier launchers refuse the field ([manifest](/reference/addons/manifest#compat)).
- Vehicle stat ids run to 16382, as driver ids do.
