# 1.9.46

Swofty Launcher for F1 25 1.9.46 fixes a fault in 1.9.45 that turned parts of career addons off, and a red flag crash.

## Careers

- F2 Revamp, Progressive Career and the launcher's own "start in F1" step work again. In 1.9.45 a new career feature took the same place in the game as they do, and the launcher turned them off at start-up. If a career addon behaved oddly on 1.9.45, update and press Play again.
- The `virtual-list` op's `"host": "career"` from 1.9.45 is removed for now.

## Crashes

- A red flag in a Grand Prix no longer crashes the game when the game has no race record for a car. Set `SWOFTY_RED_FLAG_RECOMPUTE_GUARD=0` to turn the guard off.
