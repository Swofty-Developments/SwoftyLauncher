# 1.9.78

Swofty Launcher for F1 25 1.9.78 fixes a crash on the way to the main menu, a refused **Play** after Steam's **Verify integrity of game files**, and a crash at start-up when another add-on had changed the game's import table.

## Crashes

- A driver or team whose nationality the game has no row for shows the **Other** flag instead of closing the game on the way to the main menu. SWOFTY 2012 and SWOFTY 2011 gave Vitaly Petrov a nationality the game does not have; SWOFTY 2012 1.0.10 uses **Other** too.
- The game no longer closes a few seconds after start-up when another add-on had changed entries in the game's import table. The core and the loader skip an entry they cannot read and log it once.

## Game folder

- After **Verify integrity of game files** in Steam, **Play** no longer refuses game files that are Steam's own copy.
- **Restore game folder** waits for a **Play** that is still checking the game files, then restores. If F1 25 is open, it says to close it. Files that blocked the last **Play** and are Steam's own copy stay where they are.

## Seasons

- Add-on tracks give SWOFTY 2011, 2012 and 2013 cars AI data, which targets Time Trial crashes and idle AI cars on those tracks.

## Linux

- An EA app launch command with an unquoted path that contains spaces, such as `Proton - Experimental`, runs. When the launch command cannot find its program, the message names the setting and says to put quotes around paths with spaces.
