# 1.10.26

Swofty Launcher for F1 25 1.10.26 writes a crash report for crashes where the game runs out of stack, gives addons the right session in every session of a career weekend, and sends the first Time Trial lap of a session sooner.

## Fixes

- Crashes where the game runs out of stack now leave a crash report. Before, the game could close without writing one.
- Addons now see the correct session name in each session of a career weekend, not only in the first.
- Addons that follow the game's camera, such as post-process passes limited to some views, now see the current camera after an Instant Replay that returns to the same camera, instead of an unknown view.
- The main menu's **Showroom** tile now opens the Showroom the way the game's own way in through F1 World does: it closes the main menu's video background and switches to the F1 World scene first.

## Time Trial

- The first Time Trial lap of a session now reaches the server sooner.

## Addon API

- Post-processing: on Steam 1.0.145, the wing, nose and alternate nose cameras report `wing`, `nose` and `nose_alt`, and the chase cameras report `chase_near` and `chase_far`, in `when.views`, `view.camera` rules, shader constants and the preview. Filters that select `other` no longer match these five cameras. See [When a pass runs](/reference/addons/postfx#when-a-pass-runs).
- Fixed `view.camera` rules not receiving the `trackside` and `reverse_pod` camera kinds.
- The core's lap host (`SwoftyCoreLapHost`) is at table version 4: its new `input` call lists the game controllers Windows sees (XInput slots, then HID joysticks, gamepads and multi-axis controllers such as wheels) and the core's virtual pad. See [The Time Trial plugin](/std/systems/laps#the-time-trial-plugin).
- 12 new experimental game bindings in the addon headers (`swofty/game.hpp`, `game.rs`): `Car_Engine_UpdateWear`, `Game_FfbThrustmaster_ConfigureEffects`, `Game_FrontendSceneManager_DespawnMainScene`, `Game_GarageCrewInstance_Hide`, `Game_PitLane_VehicleWantsToLeaveGarage_Thunk`, `Game_RacingFFBEffectDirectInput_UpdateDeviceEffects`, `Game_Scene_FindByName`, `Game_Teleport_VehicleImmediate_Thunk`, `Game_Update_WeatherTimelineScalar`, `Render_SceneView_BuildViewParams`, `Sess_RaceRuleset_SetTotalLaps` and `g_Game_CutscenePlacements`. `Ne_PhysUpdateStage_FinishStepNotifyBodies` is now a typed function binding.

## Addon API (experimental)

- `team.vehicle_override`, off unless `SWOFTY_VEHICLE_OVERRIDE=1`: one team's seats drive another car for chosen events of a Grand Prix box or career season. See [Vehicle overrides](/std/systems/vehicle-override).
- `track.sponsors`, off unless `SWOFTY_BOX_SPONSORS=1`: a box's own trackside sponsor boards. See [Sponsor boards](/std/systems/sponsors).
- `ui.per_package`, off unless `SWOFTY_BOX_UI=1`: a box's own UI textures, such as the FIA and F1 logos, broadcast graphics, loading screen and menu art. See [Box UI textures](/std/systems/box-ui).
- `content.package` 1.7 `world`, off unless `SWOFTY_BOX_OWN_WORLDS=1`: a box names the world its sessions load at each track. See [A world the box names](/std/systems/tracks#a-world-the-box-names).
- `content.box_assets` (work in progress), off unless `SWOFTY_BOX_ASSETS=1`: stock-named resources that only one box's sessions load.
- `swofty/game_mem.hpp`: checked writes into the game's data bindings, and memory from the game's own allocators. See [Game memory writes](/reference/std/game-memory).
- `swofty/d3d12.hpp`: `on_srv_created` runs an addon's callback after the game makes each shader resource view, from one core hook on `CreateShaderResourceView`. See [Shader resource views](/std/systems/graphics#shader-resource-views).

## Under the hood

- `loader.log` now names each physics body whose position or velocity stops being a finite number after a physics step. `SWOFTY_PHYS_NONFINITE_LOG=0` turns this off.
- Reverse-engineering notes updated.
