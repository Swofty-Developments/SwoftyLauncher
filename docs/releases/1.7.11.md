# 1.7.11

Swofty Launcher for F1 25 1.7.11 finds more Steam saves, explains more crashes and fixes several of them.

## Saves

- The Steam save is found when the game is in a Steam library on another drive. The launcher looks under the Steam install's `userdata`, which it finds from the library's owner, the registry, a running Steam and the usual Steam folders on every drive.
- When the launcher can't find your Steam save, the **Saves** page says so, with buttons to import again, choose the folder yourself, or play with your Steam saves.
- Every session logs where the game's saves come from and each career slot the game read. Send Logs lists them in a `Saves` section.

## Addons

- A damaged addon storage marker is repaired instead of stopping the launcher, and one addon's storage error no longer blocks Play.
- Team logos build when another addon shortened the logo arrays, and the build log has one line for each reason a logo was refused.
- Built textures are checked, and textures the game may reject show as warnings in the build log.
- `team.garage` art is off by default after crashes in the game's texture streaming. `SWOFTY_GARAGE_ART=1` turns it back on.
- A round at a track with no track data, such as Paul Ricard without its addon, no longer crashes Team HQ's standings or the R&D table. The round shows no track.
- An era box picked for a Grand Prix or Time Trial no longer carries into a career.

## Crashes

- When the game can't write in its own folder, the crash report and loader log go to `state` in the data folder, and Send Logs picks them up there.
- Device-removed diagnostics also turn on after the newest crash report shows the graphics device was removed.
- `SWOFTY_D3D_DEBUG=1` turns on the D3D12 debug layer and logs its errors to `loader.log` and the crash report.
- Crashes setting up the pit crew for a team's third car and reading the garage crew scene are guarded.
- Send Logs includes the EA app's logs and the Windows Application event log entries that name F1 25, EA's anti-cheat or the EA app.

## Launcher

- The launcher no longer lags when you switch profiles or type: the **Saves** page loads in the background.

## DB Editor

- **Calendar** explains that a career orders its rounds by each event's date, and the build log names rounds that a lower **Events** count drops.

## For addon makers

- `session.end` and `session.unload` fire. See [Events](/std/events#the-lifecycle).
