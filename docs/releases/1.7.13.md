# 1.7.13

Swofty Launcher for F1 25 1.7.13 repairs team logo arrays that matched crashes at boot with several season packs, and makes crash notices more accurate.

## Crashes

- A team logo texture array whose slice count disagrees with its view (for example after another addon replaced only the array's image) is repaired before the game loads it, and the logo build no longer reuses a half-built cache. A mismatched array like this matches the crashes at boot where the graphics device stopped responding with several season packs on.
- The garage setups guard also works on the EA copy.

## Crash notices

- When the game stops at startup because it can't read its hardware settings file from a Documents folder kept in OneDrive, the crash notice says so and how to fix it. `loader.log` names the file's state at startup.
- When F1 25 closes before the launcher can check the loader, the notice says so instead of blaming an antivirus.
- Crash notices never suggest turning off an addon that's built into the launcher; they point to Send Logs instead.
- With Progressive or Classic Career on, the memory crash notices keep every Classic Seasons year on and never suggest moving a round; they suggest turning off imported tracks that aren't in your calendar and other content addons instead.
