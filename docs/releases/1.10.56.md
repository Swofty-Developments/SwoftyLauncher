# 1.10.56

Swofty Launcher for F1 25 1.10.56 fixes Play stopping before the game starts for some players with track add-ons after the 1.10.54 update.

## Fixes

- Play and the add-on conflict check no longer stop with "cache/menus ... flow_car_monitor.erp: The system cannot find the file specified (os error 2)". Since 1.10.54 more track flags fit the game's menus, and a menus cache built by an older launcher could be reused without a file the new build needs. The launcher now rebuilds a menus cache that is missing any file it should hold, so the next Play works with no steps needed.
