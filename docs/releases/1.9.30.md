# 1.9.30

Swofty Launcher for F1 25 1.9.30 makes addons' memory checks cheap.

## Addons

- Addons built with the new SDK check game memory through the launcher's shared page table, which removes a large per-minute cost and its hitches on Windows. Addons built against an older SDK keep working as before and get the saving once their author rebuilds them.
- The `save_dir` host call is documented as new in 1.9.29, and the launcher addon template uses it to show the save folder.
