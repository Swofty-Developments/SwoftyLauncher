# 1.10.48

Swofty Launcher for F1 25 1.10.48 fixes racing number swaps for some drivers and makes one crash notice more precise.

## Fixes

- Changing a driver's racing number in Career Mode Editor now works for a driver with more than one entrant row. The number goes on the row he races with, and a swap no longer fails with "the driver has no number to give in a swap".

## Diagnostics

- Send Logs' crash notice about how many cars were on the grid counts only the session that crashed, so a larger grid from an earlier session in the same game no longer gets the blame.
