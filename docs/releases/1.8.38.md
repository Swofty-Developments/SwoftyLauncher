# 1.8.38

Swofty Launcher for F1 25 1.8.38 fixes the in-game overlay on some NVIDIA setups.

## Fixes

- On some NVIDIA cards, the screen the game draws to was set up by NVIDIA's Streamline layer (used by DLSS) before the launcher could see it, so the overlay never drew: addon panels such as Silly Season's F7 panel and toasts didn't show, with Frame Generation on or off. The core now asks that screen which queue it draws with and draws the overlay there. When it can't find out, the overlay stays off as before.
