# 1.9.18

Swofty Launcher for F1 25 1.9.18 brings back the faster game memory checks that 1.9.16 tried, built a new way that raises no exceptions, so In-game leaderboards no longer costs frame rate in Time Trial or anywhere else.

## Performance

- The core checks whether game memory is safe to read with one table shared by every game thread. A page it hasn't seen yet is looked up on its own instead of through VirtualQuery, which on Windows walks the whole of the game's multi-GB heaps and took about 3.5 ms each time. A check now takes well under a microsecond. It never touches memory to test it, so it can't crash the game the way 1.9.16 did, and it leaves the game's guard pages alone.
