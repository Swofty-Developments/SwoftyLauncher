## Question
On a ~20 km own track in a 2-PC online lobby, with (a) no TSQuadTree resource (runtime rebuild, 255 points, ~82 m spacing) and (b) a stored tree with 255 points, are remote cars placed correctly, and how often is the 0xff whole-box anchor sent?

## Hypothesis
`g_Game_TSQuadTree` 0x1460bff88 is read only by network code. `Game_Network_DeserialiseVehicle` 0x14326a9c0 reads a u8 anchor (0xff = whole tree box, cmp at 0x14326b251; else index < count at 0x14326b25b). Sparse points push more cars onto the whole-box path = lower position precision, no crash. Offline sessions never read the tree (T320 c).
