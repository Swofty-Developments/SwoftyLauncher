# T250 Does a wheel button bound to a UDP Action reach the BUTN mask and the action handle while driving an era car without ERS/DRS?

- Requested by: engine-re, 2026-11-18
- Status: draft
- Session: (filled by the lead when batched)

## Question
With a DirectInput wheel, bind one wheel button to "UDP Action 1" in the in-game controls menu. While driving a car without ERS/DRS (a 1950-2013 era season car), does holding the button set bit 20 of the mask that `Game_TelemetryUdp_UpdateButtons` (0x142cf8850) builds, and does `Ne_InputMapper_IsActionReleased` (0x1441165b0) on handle `g_Game_UdpButtonActionHandles[20]` (0x14607caf0) return 1 while held and 0 when released?

## Hypothesis
Static (session.md#input-actions): the 32 handles at 0x14607ca50 are queried with 0x1441165b0 for both local players; bits 20..31 are UDP Action 1..12. Nothing in that path looks at the car, so an era car changes nothing.

## Promotes
- `Game_TelemetryUdp_UpdateButtons` (L2 -> L3), `g_Game_UdpButtonActionHandles` (L2 -> L3), the held-state note on `Ne_InputMapper_IsActionReleased`

## User steps
1. Settings > Controls: bind one wheel button to UDP Action 1 and another to UDP Action 2.
2. Telemetry settings: UDP on (any format).
3. Time trial or GP with an era car without ERS/DRS: hold the UDP Action 1 button 2 s, release, then the same with UDP Action 2.

## Expected log lines
- `butn mask=0x00100000` while UDP Action 1 is held, `0x00200000` for UDP Action 2, `0x0` after release.
Pass rule: the bits follow the buttons. Fail rule: the mask stays 0 or other bits move.
