## Hypothesis
`Trk_ChampionshipEntity_TrackDataQuery_Body` builds the query from the setup mode (+0x2b0) and the selected entrant list's u16 at +0xb0 (season, used flag); `Game_TrackData_GetTrack` takes the first set holding the bits (kb:subsystems/tracks.md#query). Stock 2026 GP: mode 13, season 8 used, matches f1_2026. CS 2016 GP: mode 20 (swofty_f1); if its entrant list has no season (season_used 0) the first set listing swofty_f1 matches, which explains the f1_2026-like fuel.
