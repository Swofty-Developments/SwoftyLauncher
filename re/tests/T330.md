## Question
With a hook that adds a fifth MFD fuel row and swaps the carrier mix's scales while that row is selected, does the car run on the fifth mix's values, and does the row survive a flashback and a qualifying lap start?

## Hypothesis
`Game_Mfd_FuelMix_AddRow` 0x141789520 and `Game_Mfd_FuelMix_SetSelected` 0x1417891f0 take any mix id, so a fifth row (id 4) shows when bit 4 is stored at sub+0x324 and both mask compares (0x14178897d in `Game_Mfd_FuelMix_Update`, 0x141788ef9 in `Game_Mfd_FuelMix_Recheck`) see the same bit. The physics side uses the existing `fuel_ecu.*` layer path on the carrier mix; `CarFuelEcu.fuel_mode` stays 0..3, so the snapshot (2 bits, 0x14470e07c) restores the carrier and the hook re-applies. re/research/fuel_mix_five.md#route.

## Promotes
- `Game_Mfd_FuelMix_AddRow`, `Game_Mfd_FuelMix_SetSelected`, `Game_Mfd_FuelMix_Update`, `Game_Mfd_FuelMix_Recheck`, `Game_Mfd_FuelMix_BuildOptions` (row and mask behaviour).

## Build
- exe: the runtime build the add-on targets (addresses via the KB signatures); swofty_core with the fifth-mix hook; a test add-on with fifth-mix scales clearly different from the carrier (e.g. power 1.10, burn 1.30).

## Trace config
1. Log sub+0x324 after each BuildOptions call and the row count of sub+0x350.
2. Log the player's CarFuelEcu +0x128 and the four active pairs (+0x130..+0x160, decoded) once per second.

## User steps
1. Grand Prix, practice, own car. Open the fuel MFD: is there a fifth row with the add-on's text?
2. Step up to it and back down twice. 3. On the fifth row drive one lap; note fuel use per lap from the MFD.
3. Flashback once on the fifth row. 4. Qualifying: start a flying lap on the fifth row.

## Expected log lines
- mask 0x1f with five rows -> the row code is generic.
- active power/burn = fifth values while row 5, carrier values after stepping down.
Pass rule: row shows, values follow, flashback and lap start keep or re-apply row 5, no per-frame rebuild (BuildOptions count does not grow every frame). Fail rule: the row disappears or the list rebuilds every frame.
