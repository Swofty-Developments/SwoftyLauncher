# T013 Does View Leaderboards in Time Trial return to the track select without a crash while the game runs offline?

- Requested by: lbguard, 2026-10-29
- Status: draft
- Session: (filled by the lead when batched)

## Question
With the Time Trial leaderboard guard in core, does pressing View Leaderboards in Time Trial (the 1.5.34 and 1.5.35 crash, `ACCESS_VIOLATION reading 0x98 at F1_25.exe+0x2fce9e3` through `Vm_Dispatch_BindingMessage` on `leaderboard_container`) leave the game running?

## Hypothesis
`Game_TimeTrialLeaderboard_SelectBoard` builds the board key `LBV%02u%02d%s` from the track and the weather and searches the reader's board list (`*(*(reader+0x478)+0x10)`, +0x18..+0x20) for the board whose name (+0x68) matches. With the online services off the list holds no board for the key, the search leaves 0 in rcx and `site_Game_TimeTrialLeaderboard_BoardRead` (`game.time_trial_leaderboard_board_read`) reads the board's thresholds through it. The guard sets the function's result to false and continues at `site_Game_TimeTrialLeaderboard_BoardsDone` (`game.time_trial_leaderboard_boards_done`), the function's own cleanup. One of the two callers (0x142fc8910) tests the result and takes its failure branch, the other (0x142fcc667) ignores it. What the screen shows afterwards, and whether the view model keeps working, is not known.

## Promotes
- `site_Game_TimeTrialLeaderboard_BoardRead`, `site_Game_TimeTrialLeaderboard_BoardsDone`, `Game_TimeTrialLeaderboard_SelectBoard`: L2 -> L3 on the build the run used.
- A crash inside 0x142fce500..0x142fcef6f or in 0x142fc8910 right after the skip demotes the "result false is a clean failure" claim and keeps the guard off.

## User steps
1. Launch through the launcher with any addon enabled. At the home screen, check `loader.log` for the guard lines (below).
2. Time Trial: pick a track and a car, and on the track select screen press View Leaderboards.
3. Note what the screen does (empty board, error popup, or nothing), then back out to the track select and press View Leaderboards a second time.
4. Change the track and the weather, press View Leaderboards again, then start a lap and return to the menu.
5. Quit from the main menu and keep `loader.log`.

## Expected log lines
- `core mixin set 'swofty_core\.dll \(time trial leaderboard guard\)': 1 mixin` → the guard was offered.

Pass rule: steps 2 to 4 finish without a crash and the first three lines are logged. Fail rule: any crash with `F1_25.exe+0x2fce` or `+0x2fc2` (EA) in its stack, or the guard lines missing.
