## Question
Does an own track with 1500 main-route AI gates load and race when every marker channel stays <= 200, and does it crash in Game_AiRoute_CompileMarkerChannel as soon as ONE channel exceeds 256 on one route?

## Hypothesis
`Game_AiSplineData_ReadGates` 0x14067bf30 has no gate cap and the lane index is u16 (`Game_AiRoute_BuildGraph` 0x14067d510), so 1500 gates load. `Game_AiRoute_CompileMarkerChannel` 0x140677ae0 keeps 256-entry stack arrays per channel (inc r9d at 0x140677d00, no bound); the heap block is sized by `Game_AiRoute_CalcLaneBufferSize_Thunk` 0x140677910. Expected: 1500 gates + <= 200 markers per channel = loads; 257+ brake_lines (or width-class changes) on one route = crash at load.

## Promotes

## User steps

## Expected log lines
- gate count 1500 and a normal race for (a) -> proves no gate cap at 1500.
- crash during load for (b) with the last trace inside 0x140677ae0 -> proves the 256 channel limit.
Pass rule: (a) and (c) race, (b) crashes in 0x140677ae0. Fail rule: (a) crashes (then a gate-count limit exists elsewhere) or (b) loads.
