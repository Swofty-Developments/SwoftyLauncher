## Question
On a car whose EngineModeAvail mask allows no ERS mode, with a wheel button bound to "ERS Mode Up": does `Ne_InputMapper_IsActionPressed` (0x1441162f0) on the interned handle at `g_Game_MfdActionHandles+0xa8` (0x146078d38) fire once per press, does `Game_GameMfdSystem_Update` (0x142a8e070) call `Game_Mfd_ErsUp` (0x141534290), and does InputRecord+0x08 stay unchanged?

## Hypothesis
Static: the MFD system polls the handle behind a 0.25 s repeat gate and calls Game_Mfd_ErsUp, which returns without writing when no mode bit is set or ERS assist is on. So the press is detectable (handle query, or a hook on the Game_Mfd_ErsUp entry) even when the car has no ERS, with no visible game effect.
