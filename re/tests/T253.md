# T253 Does the legacy KERS action plus Engine KERSPower/KERSCapacity give a boost on an era car?

- Requested by: engine-re, 2026-11-18
- Status: draft
- Session: (filled by the lead when batched)

## Question
If an action map binds the action name "KERS" (absent from every stock actionmaps/*.xml) to a wheel button and the car VTF sets Engine/KERSPower and Engine/KERSCapacity, does holding the button (InputRecord bit7 -> CarLive+0x1b8 bit1 -> Engine+0x2568) drain kers_energy (Engine+0x2540) and give a non-zero Engine+0x2564 in `Car_Engine_StepInput` (0x144688610, site 0x144688d2b), and does the car accelerate harder?

## Hypothesis
Static: Sess_HumanController_Update interns and reads "KERS" (0x146105f60); Car_Physics_AdvanceCar copies CarLive+0x1b8 bit1 to Engine+0x2568 (0x144740355); StepInput turns it into a torque P / rotation_rate limited by the stored energy. Open statically: whether a user action map may bind "KERS", and whether +0x2564 reaches the drive torque.

## Promotes
- the KERS note on `Car_Engine_StepInput`, `CarEngine.kers_energy` (L2 -> L3); demotes the KERS-boost idea if +0x2564 stays 0 or has no effect

- install: only `version.dll` and `swofty/` plus the test data

## Trace config
Trace-only, 5/s: at 0x144688d2b log byte [rsi+0x2568] and floats [rsi+0x2540], [rsi+0x2564], [rsi+0x2538].

## User steps
1. Install the test data, start a time trial with the era car.
2. On a straight in 4th gear at full throttle hold the KERS button 5 s; repeat without the button.

## Expected log lines
- `kers btn=1 energy=` falling from 400000 and `out=` > 0 while held; energy flat and out=0 without the button.
Pass rule: energy drains and out > 0 only while held (then compare the speed traces). Fail rule: btn stays 0 (binding not accepted) or out stays 0.
