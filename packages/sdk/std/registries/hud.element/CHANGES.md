Dial fit: decision `initial`, variant `decisions` and `root_y`, `add` entries placed with `before` / `after` / `replace`, record `root_y`. Motion: `motion` on a group (`id`, `keys`, `curve`, `play_on`) for a timed slide or fade. Game values and stock parts: bind `path` (any game view-model path, `ty` si32/ui32/text/bool), element `colour` (a static colourOverride) and `hidden` as a static hide node, `stock_nodes.wrap` (a new null around a stock part another node targets), `also.<screen>.hide`, the record field `clock` (`output`, `start`), decisions `on` a path for screen records; a leaf declared `i32` binds si32 (the core writes int leaves as signed ints).
