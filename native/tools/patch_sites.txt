# Every line in native/src (core, loader, gamelog) that writes code in the game exe, or forwards to one that does,
# with what it writes and where. tools/patch_sites.py --check fails when a line that writes code is missing here, and
# the build writes patches.json from this list, the core's mixin tables and the binding sets.
#
# An entry is "<source>: <the line, trimmed> => <write> <targets>".
#
# Writes that put sites in patches.json:
#   inline     an inline hook (safetyhook InlineHook): a jump at the start, over whole instructions
#   mid        a mid hook (safetyhook MidHook): the same, at a site inside a function
#   bytes=<n>  n bytes written at the site
#   call       the rel32 of a call at the site (5 bytes)
#   vtable     vtable slots (8 bytes each)
#   import     slots of the exe's import address table, named <dll>!<function>..., either part * for any
# Writes that do not:
#   via        a step of an install another entry or a mixin table names (a helper, an overload)
#   outside    code outside the game exe (a system or graphics DLL); the module follows
#   none       the line matches but writes no code (a declaration, a method named install, a data write)
#
# Targets:
#   sig <NAME>... | sig <file>:<NAME>      a runtime::Sig or Target declared in the source, its includes or its folder
#   sigs-in <file>...                      every signature the file declares
#   binding <id or string constant>...     a binding (re/bindings); <file>:<constant> for a constant in another file
#   binding-consts <NAME>                  every "<NAME> = "<binding>"" in the source
#   spec <NAME>...                         the binding of a hook point Spec NAME{"<point>", "<binding>"}
#   rel32 <SIG> <offset>                   the call whose rel32 sits at offset past the signature's site
#   prologue <RVA> <PATTERN> [on <STAMP>=<RVA>]...   a function found by its prologue in any code section
#   tag <word>                             the install's tag; a gated install's tag is read from its line
#
# "helper [<file>] <regex>" makes every line the regex matches (in that file only, when one is given) a line that
# must be listed, for the callers of a helper whose own line is a via.
